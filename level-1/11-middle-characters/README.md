# 🧩 가운데 글자 가져오기

- Programmers ID: 12903
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12903
- Level: 1
- Stage: Level 1 Core 11
- Prerequisites: 문자열, `len()`, 인덱싱, 슬라이싱, `//`
- Core concepts: 홀짝에 따른 위치 계산

## 🎯 이 문제에서 배우는 것

문자열 길이가 홀수인지 짝수인지에 따라 가운데 위치를 다르게 고릅니다.

## 🔎 문제 핵심

문자열 `s`에서 가운데 글자를 돌려줍니다. 길이가 홀수이면 한 글자, 짝수이면 가운데 두 글자가 결과입니다.

## 💭 먼저 생각해 보기

다섯 칸과 여섯 칸을 그려 양쪽 끝을 하나씩 지워 보세요. 마지막에 남은 칸의 개수와 인덱스를 확인하세요.

## 🧪 예제 이해하기

`s = "piano"`는 길이가 5라 인덱스 2의 `"a"`가 가운데입니다. `s = "planet"`은 길이가 6이라 인덱스 2와 3의 `"an"`을 돌려줍니다.

```text
인덱스: 0 1 2 3 4 5
글자:   p l a n e t
            ^ ^
```

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

길이를 2로 나눈 몫을 `middle`에 저장합니다. 홀수 길이면 그 위치 하나를, 짝수 길이면 바로 앞 위치까지 포함한 두 글자를 고릅니다.

### 🐍 Python 코드

```python
def solution(s):
    middle = len(s) // 2
    if len(s) % 2 == 1:
        return s[middle]
    return s[middle - 1:middle + 1]
```

### 📖 코드 해설

인덱스는 0부터 시작합니다. 길이 6일 때 `middle`은 3이므로 두 글자의 위치는 2와 3입니다. 슬라이싱은 끝 위치를 포함하지 않아 `s[2:4]`로 써야 합니다.

### ⏱️ 시간 복잡도

문자열 길이를 `n`이라 해도 길이 읽기와 위치 계산은 `O(1)`입니다. 복사하는 글자도 최대 두 개이므로 시간은 `O(1)`입니다.

### 💾 공간 복잡도

반환 문자열이 최대 두 글자이므로 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `len(s) / 2`는 소수가 될 수 있어서 인덱스로 바로 쓸 수 없습니다.
- 짝수 길이에서 `middle`과 `middle + 1`을 고르면 오른쪽으로 한 칸 밀립니다.

## ✅ 배운 것

문자열 길이와 인덱스는 시작 기준이 다릅니다. 칸을 그려 위치를 확인하면 실수를 줄일 수 있습니다.
