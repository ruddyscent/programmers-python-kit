## 🎯 이 문제에서 배우는 것

두 리스트의 같은 위치를 짝지어 계산한 값을 하나의 합계로 모읍니다.

## 🔎 문제 핵심

길이가 같은 정수 리스트 `a`, `b`가 주어집니다. 같은 위치의 두 수를 곱하고 그 곱을 모두 더한 값을 돌려줍니다. 이 계산을 내적이라고 부릅니다.

## 💭 먼저 생각해 보기

`[2, -3, 4]`와 `[5, 2, -1]`을 위아래로 적고 같은 위치만 선으로 연결해 보세요. 몇 번의 곱셈이 필요할까요?

## 🧪 예제 이해하기

각 위치의 곱은 `2 * 5 = 10`, `-3 * 2 = -6`, `4 * -1 = -4`입니다. 합계는 0입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

인덱스를 하나씩 늘리며 같은 위치의 두 수를 곱합니다. 곱을 따로 모으지 않고 바로 합계에 더합니다.

### 🐍 Python 코드

```python
def solution(a, b):
    total = 0
    for index in range(len(a)):
        total += a[index] * b[index]
    return total
```

### 📖 코드 해설

`a[index]`와 `b[index]`는 같은 위치를 가리킵니다. 곱셈을 먼저 한 다음 `total`에 더합니다. 각 리스트의 합계를 먼저 구해 곱하면 서로 다른 위치끼리의 곱까지 섞이므로 다른 계산이 됩니다.

### ⏱️ 시간 복잡도

두 리스트의 공통 길이를 `n`이라 하면 곱셈과 덧셈을 각각 `n`번 하므로 `O(n)`입니다.

### 💾 공간 복잡도

중간 곱들을 모은 리스트가 없습니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 음수끼리 곱하면 양수입니다. 부호를 지우지 않습니다.
- 두 리스트를 따로 정렬하면 원래 짝이 바뀝니다.
- `sum(a) * sum(b)`는 같은 위치끼리 곱한 합과 다릅니다.

## ✅ 배운 것

같은 위치의 값끼리 계산하는 문제에는 하나의 반복문이면 충분합니다.
