# 🧩 짝수와 홀수

- Programmers ID: 12937
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12937
- Level: 1
- Stage: Level 1 Core 01
- Prerequisites: 함수, `return`, 조건문, 나머지 `%`
- Core concepts: 짝수 판별, 문자열 반환

## 🎯 이 문제에서 배우는 것

2로 나눈 나머지를 보고 짝수와 홀수를 구분합니다. 계산한 수가 아니라 약속된 문자열을 돌려주는 연습도 합니다.

## 🔎 문제 핵심

입력 `num`은 정수입니다. 짝수이면 `"Even"`, 홀수이면 `"Odd"`를 돌려줍니다. 0도 짝수에 들어갑니다.

## 💭 먼저 생각해 보기

구슬 8개를 두 개씩 묶으면 남는 구슬이 있나요? 9개일 때와 비교하고 이 차이를 `%`로 어떻게 확인할지 말해 보세요.

## 🧪 예제 이해하기

`num = 8`이면 `8 % 2`는 0이므로 결과는 `"Even"`입니다. `num = -5`이면 `-5 % 2`는 1이므로 `"Odd"`입니다. 음수도 나머지가 0인지 확인하면 됩니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

나머지가 0인 경우 먼저 반환합니다. 그 경우가 아니라면 홀수이므로 마지막 줄에서 `"Odd"`를 반환합니다.

### 🐍 Python 코드

```python
def solution(num):
    if num % 2 == 0:
        return "Even"
    return "Odd"
```

### 📖 코드 해설

`num % 2`는 2로 나눈 나머지입니다. `== 0`은 그 나머지가 0인지 묻습니다. `return`을 만나면 함수가 끝나므로 짝수일 때 마지막 줄까지 내려가지 않습니다.

### ⏱️ 시간 복잡도

정수 하나에 나머지 계산과 비교를 한 번씩 합니다. 문제 범위의 정수 연산을 한 번의 계산으로 세면 시간은 `O(1)`입니다.

### 💾 공간 복잡도

입력 외에 크기가 늘어나는 자료를 만들지 않습니다. 반환 문자열까지 포함해 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `"even"`과 `"Even"`은 다른 문자열입니다. 첫 글자의 대소문자를 맞춥니다.
- 짝수 판별에 `/`를 쓰지 않습니다. 필요한 것은 나눈 값이 아니라 나머지입니다.

## ✅ 배운 것

나머지가 0인지 비교하면 음수를 포함한 정수의 짝수 여부를 알 수 있습니다.
