# 🧩 문자열 내림차순으로 배치하기

- Programmers ID: 12917
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12917
- Level: 1
- Stage: Level 1 Core 19
- Prerequisites: 문자열, `sorted()`, 대소문자
- Core concepts: 내림차순, `join()`

## 🎯 이 문제에서 배우는 것

문자들을 정렬한 리스트로 만든 뒤 다시 문자열로 합칩니다.

## 🔎 문제 핵심

영문 대소문자로 된 문자열 `s`를 큰 글자부터 작은 글자 순서로 배치합니다. 이 문제에서는 소문자가 대문자보다 큽니다. 결과는 새 문자열입니다.

## 💭 먼저 생각해 보기

`"bAaC"`에서 소문자와 대문자를 나누어 보고 각 묶음 안의 순서도 생각해 보세요. 알파벳 이름이 같아도 대소문자가 다르면 같은 글자로 다루지 않습니다.

## 🧪 예제 이해하기

`s = "bAaC"`를 내림차순으로 정렬하면 `b`, `a`, `C`, `A`입니다. 결과 문자열은 `"baCA"`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

`sorted()`에 `reverse=True`를 주어 큰 글자부터 정렬합니다. 글자 리스트를 빈 문자열의 `join()`으로 이어 붙입니다.

### 🐍 Python 코드

```python
def solution(s):
    characters = sorted(s, reverse=True)
    return "".join(characters)
```

### 📖 코드 해설

`reverse=True`는 정렬 방향을 내림차순으로 지정하는 인자입니다. 영문자에 대한 Python의 문자 순서는 이 문제의 대소문자 규칙과 맞습니다. `sorted(s)`의 결과는 문자열이 아니라 글자 리스트이며 `"".join(characters)`는 글자 사이에 아무것도 넣지 않고 연결합니다. 예를 들어 `"-".join(["a", "b"])`는 `"a-b"`가 됩니다.

### ⏱️ 시간 복잡도

글자 수를 `n`이라 하면 정렬은 최악 `O(n log n)`, 연결은 `O(n)`입니다. 전체는 `O(n log n)`이며 한 글자라면 일정한 작업으로 끝납니다.

### 💾 공간 복잡도

정렬된 글자 리스트와 정렬용 임시 공간, 반환 문자열을 합쳐 추가 공간은 `O(n)`입니다.

## ⚠️ 실수하기 쉬운 점

- `s[::-1]`은 원래 순서를 뒤집을 뿐 크기순으로 정렬하지 않습니다.
- `lower()`를 사용하면 원래 대문자가 바뀌므로 요구한 결과와 달라집니다.
- 반환값에 리스트의 대괄호가 남아 있지 않은지 확인합니다.

## ✅ 배운 것

`sorted()`로 얻은 글자 리스트를 `join()`으로 문자열로 만들 수 있습니다.
