# 🧩 핸드폰 번호 가리기

- Programmers ID: 12948
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12948
- Level: 1
- Stage: Level 1 Core 14
- Prerequisites: 문자열 반복, `len()`, 슬라이싱
- Core concepts: 끝 기준 인덱스, 문자열 결합

## 🎯 이 문제에서 배우는 것

문자열을 가릴 부분과 남길 부분으로 나누고 다시 연결합니다.

## 🔎 문제 핵심

문자열 `phone_number`의 마지막 네 글자는 그대로 두고 그 앞을 `*`로 바꿉니다. 결과도 문자열입니다.

## 💭 먼저 생각해 보기

연습용 문자열 `"12345678"`을 앞부분과 마지막 네 글자로 나누어 보세요. 별표는 몇 개 필요할까요?

## 🧪 예제 이해하기

`"12345678"`의 길이는 8이라 네 글자를 가립니다. `"****"`와 `"5678"`을 이어 결과 `"****5678"`을 만듭니다. 길이가 4인 `"2468"`은 그대로입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

전체 길이에서 4를 빼 가릴 글자 수를 구합니다. 그 수만큼 별표를 만들고 뒤 네 글자를 붙입니다.

### 🐍 Python 코드

```python
def solution(phone_number):
    hidden_count = len(phone_number) - 4
    hidden = "*" * hidden_count
    visible = phone_number[-4:]
    return hidden + visible
```

### 📖 코드 해설

음수 인덱스는 뒤에서 셉니다. `-1`은 마지막, `-4`는 뒤에서 네 번째 위치입니다. `phone_number[-4:]`는 그 위치부터 끝까지 가져옵니다. 문자열에 정수를 곱하면 글자가 반복되고 `+`로 문자열을 이으면 새 문자열이 만들어집니다.

### ⏱️ 시간 복잡도

번호의 길이를 `n`이라 하면 별표와 최종 문자열을 만드는 데 `O(n)`의 시간이 듭니다. 뒤 네 글자만 가져오는 작업은 `O(1)`입니다.

### 💾 공간 복잡도

별표 문자열과 최종 결과에 길이에 비례하는 공간을 씁니다. 반환 문자열을 포함한 추가 공간은 `O(n)`입니다.

## ⚠️ 실수하기 쉬운 점

- 번호를 정수로 바꾸면 앞의 0을 잃을 수 있습니다. 문자열로 처리합니다.
- 가릴 글자 수가 0이면 `"*" * 0`은 빈 문자열입니다.

## ✅ 배운 것

뒤에서부터 고정된 수의 글자를 가져올 때 음수 인덱스로 슬라이싱할 수 있습니다.
