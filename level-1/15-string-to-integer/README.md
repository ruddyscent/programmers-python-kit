# 🧩 문자열을 정수로 바꾸기

- Programmers ID: 12925
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12925
- Level: 1
- Stage: Level 1 Core 15
- Prerequisites: 문자열과 정수의 차이, `return`
- Core concepts: `int()`, 부호가 있는 수

## 🎯 이 문제에서 배우는 것

겉으로 같은 숫자처럼 보여도 자료형에 따라 할 수 있는 일이 다르다는 점을 익힙니다.

## 🔎 문제 핵심

숫자를 적은 문자열 `s`를 계산할 수 있는 정수로 바꿔 돌려줍니다. 맨 앞에 `+` 또는 `-`가 붙을 수 있으며 입력은 올바른 정수 표현입니다.

## 💭 먼저 생각해 보기

`"27"`과 정수 `27`은 어떻게 다를까요? 글자를 잇는 것과 수를 더하는 것을 구별해 보세요.

## 🧪 예제 이해하기

`s = "-27"`이면 결과는 정수 `-27`입니다. `s = "+64"`이면 결과는 64입니다. 결과를 표시할 때 문자열의 따옴표는 남지 않습니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

부호를 직접 떼어 낼 필요 없이 내장 함수 `int()`에 문자열을 전달합니다.

### 🐍 Python 코드

```python
def solution(s):
    return int(s)
```

### 📖 코드 해설

`int()`는 `"27"`, `"+27"`, `"-27"`처럼 부호가 있는 숫자 문자열도 정수로 바꿉니다. 정수로 바꾼 다음에는 덧셈과 뺄셈을 할 수 있습니다. 이 문제는 입력이 올바르다고 보장하므로 별도의 오류 처리는 필요하지 않습니다.

### ⏱️ 시간 복잡도

문자열 길이를 `d`라 하면 문제 범위의 짧은 문자열을 왼쪽부터 해석하는 작업을 `O(d)`로 셉니다. 입력 길이 제한 안에서는 계산량도 작고 제한되어 있습니다.

### 💾 공간 복잡도

문제에서 허용한 정수 크기를 한 칸으로 세면 반환 정수를 포함한 추가 공간은 `O(1)`입니다. 끝없이 긴 정수 문자열의 저장 비용까지 뜻하는 설명은 아닙니다.

## ⚠️ 실수하기 쉬운 점

- `return s`는 원래 문자열을 그대로 돌려줍니다.
- 음수 부호를 버리면 음수를 양수로 바꾸게 됩니다.

## ✅ 배운 것

이미 준비된 내장 함수가 필요한 동작을 정확히 한다면 그대로 사용할 수 있습니다.
