# 🧩 나머지가 1이 되는 수 찾기

- Programmers ID: 87389
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/87389
- Level: 1
- Stage: Level 1 Core 09
- Prerequisites: `range()`, `%`, `for`, `return`
- Core concepts: 작은 후보부터 탐색, 첫 답 반환

## 🎯 이 문제에서 배우는 것

답이 될 수 있는 수를 작은 순서로 확인하여 가장 작은 답을 찾습니다.

## 🔎 문제 핵심

`n`을 어떤 자연수로 나눈 나머지가 1이 되어야 합니다. 그런 수 중 가장 작은 수를 돌려줍니다. 입력은 3 이상이므로 답이 존재합니다.

## 💭 먼저 생각해 보기

16을 2와 3으로 차례대로 나누어 나머지를 적어 보세요. 처음으로 나머지가 1인 수를 찾으면 뒤의 수까지 확인해야 할까요?

## 🧪 예제 이해하기

`n = 16`이면 2로 나눈 나머지는 0입니다. 3으로 나누면 나머지가 1이므로 결과는 3입니다. 더 큰 후보에도 답이 있을 수 있지만 가장 작은 답은 이미 찾았습니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1로 나눈 나머지는 언제나 0이므로 후보를 2부터 확인합니다. 조건에 맞는 첫 수를 찾으면 즉시 반환합니다. `n - 1`로 나누면 나머지가 1이므로 늦어도 그때 답을 찾습니다.

### 🐍 Python 코드

```python
def solution(n):
    for divisor in range(2, n):
        if n % divisor == 1:
            return divisor
```

### 📖 코드 해설

`range(2, n)`에는 마지막 후보 `n - 1`이 들어갑니다. 후보를 작은 순서로 확인하므로 첫 번째로 찾은 값이 가장 작은 답입니다. `return`은 반복문뿐 아니라 함수 전체를 끝냅니다.

### ⏱️ 시간 복잡도

입력값 `n`에 대해 최악에는 2부터 `n - 1`까지 확인합니다. 따라서 시간은 `O(n)`입니다.

### 💾 공간 복잡도

후보 하나씩만 확인하므로 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 나머지가 0인 약수를 찾는 문제와 구별합니다.
- 후보를 큰 순서로 확인하면 첫 번째 답이 최솟값이라는 보장이 없습니다.

## ✅ 배운 것

가장 작은 값을 찾을 때 작은 후보부터 확인하면 처음 찾은 답을 바로 반환할 수 있습니다.
