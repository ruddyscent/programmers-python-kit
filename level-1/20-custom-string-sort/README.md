# 🧩 문자열 내 마음대로 정렬하기

- Programmers ID: 12915
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12915
- Level: 1
- Stage: Level 1 Core 20
- Prerequisites: 문자열 인덱싱, 함수, `sorted()`
- Core concepts: 정렬 기준 함수, 튜플, 같은 기준값의 순서

## 🎯 이 문제에서 배우는 것

정렬에 사용할 값을 함수로 정하고 첫 기준이 같을 때 사용할 두 번째 기준도 정합니다.

## 🔎 문제 핵심

문자열 리스트 `strings`를 각 문자열의 인덱스 `n`에 있는 글자로 정렬합니다. 그 글자가 같으면 단어 전체의 사전순으로 정렬합니다. 모든 단어에 해당 인덱스가 존재합니다.

## 💭 먼저 생각해 보기

`["cat", "bag", "bee"]`의 인덱스 1 글자를 적어 보세요. 같은 글자를 가진 단어 둘의 앞뒤는 무엇으로 정하면 될까요?

## 🧪 예제 이해하기

`n = 1`일 때 `"cat"`과 `"bag"`의 기준 글자는 a이고 `"bee"`는 e입니다. a인 두 단어 중 `"bag"`이 사전순으로 앞이므로 결과는 `["bag", "cat", "bee"]`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

각 단어를 정렬할 때 `(기준 글자, 단어 전체)`를 비교하도록 함수를 만듭니다. 괄호와 쉼표로 묶은 값을 튜플이라고 합니다. 튜플은 앞의 값부터 비교하고 같으면 다음 값을 비교합니다.

### 🐍 Python 코드

```python
def solution(strings, n):
    def sort_key(word):
        return (word[n], word)

    return sorted(strings, key=sort_key)
```

### 📖 코드 해설

`sort_key`는 `solution` 안에서 정의한 함수라 바깥의 `n`을 읽을 수 있습니다. `key=sort_key`는 각 원소를 비교할 기준을 이 함수로 구하라는 뜻입니다. 여기에는 `sort_key()`처럼 호출 결과를 넣지 않고 함수 이름을 전달합니다. `("a", "bag")`와 `("a", "cat")`은 첫 값이 같아 두 번째 값을 비교합니다. [Python 정렬 안내](https://docs.python.org/3/howto/sorting.html#key-functions)에서도 기준 함수의 사용법을 볼 수 있습니다. 입력 리스트는 바꾸지 않습니다.

### ⏱️ 시간 복잡도

단어 수를 `m`, 가장 긴 단어의 길이를 `L`이라고 하겠습니다. 기준 글자는 바로 읽지만 첫 기준이 같으면 단어 비교에 최악 `O(L)`이 듭니다. 정렬 전체의 최악 시간은 `O(m log m × L)`입니다. 단어가 하나라면 일정한 작업으로 끝납니다.

### 💾 공간 복잡도

각 단어의 기준 튜플, 정렬용 임시 공간, 반환 리스트에 `O(m)`의 추가 공간을 씁니다. 튜플에는 원래 단어를 가리키는 참조를 저장하며 단어 전체를 복사하지 않습니다. 반환 리스트를 포함한 값입니다.

## ⚠️ 실수하기 쉬운 점

- `word[n]`만 기준으로 쓰면 같은 글자인 단어들의 사전순을 보장하지 못합니다.
- `n`은 0부터 세는 인덱스입니다.
- 문자열을 직접 바꾸지 말고 비교에 사용할 값을 따로 만듭니다.

## ✅ 배운 것

정렬 기준을 여러 개 묶으면 첫 기준이 같은 경우의 순서까지 정할 수 있습니다.
