# 🧩 문자열 내 p와 y의 개수

- Programmers ID: 12916
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12916
- Level: 1
- Stage: Level 1 Core 12
- Prerequisites: 문자열 순회, `if`, `elif`, 누적 개수
- Core concepts: 대소문자 통일, 두 개수 비교

## 🎯 이 문제에서 배우는 것

같은 것으로 다룰 글자의 모양을 먼저 맞춘 뒤 개수를 셉니다.

## 🔎 문제 핵심

문자열 `s`에서 p와 y가 나온 횟수를 비교합니다. 대문자 P와 Y도 각각 같은 글자로 셉니다. 두 개수가 같으면 `True`, 다르면 `False`입니다.

## 💭 먼저 생각해 보기

`"PyAp"`를 보고 p 종류와 y 종류를 각각 표시해 보세요. 대문자를 소문자로 고쳐 쓰면 어떤 조건문이 필요할까요?

## 🧪 예제 이해하기

`"PyAp"`를 소문자로 바꾸면 `"pyap"`입니다. p는 2개, y는 1개라 `False`입니다. `"abc"`에서는 둘 다 0개이므로 `True`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

`lower()`로 모두 소문자로 바꿉니다. p를 만나면 p의 개수를, y를 만나면 y의 개수를 늘립니다. 다른 글자는 지나갑니다.

### 🐍 Python 코드

```python
def solution(s):
    p_count = 0
    y_count = 0
    for character in s.lower():
        if character == "p":
            p_count += 1
        elif character == "y":
            y_count += 1
    return p_count == y_count
```

### 📖 코드 해설

`s.lower()`는 소문자로 바꾼 문자열을 돌려주는 메서드입니다. 메서드는 `문자열.이름()`처럼 점을 붙여 호출합니다. 원래 문자열 `s`를 고치지는 않습니다. 한 글자가 p이면서 y일 수는 없으므로 `elif`로 나누었습니다.

### ⏱️ 시간 복잡도

문자열 길이를 `n`이라고 하면 소문자 변환과 순회가 각각 `O(n)`입니다. 두 번의 선형 작업을 합쳐도 시간은 `O(n)`입니다.

### 💾 공간 복잡도

길이 `n`인 소문자 문자열을 만듭니다. 개수를 세는 변수와 반환값까지 포함한 추가 공간은 `O(n)`입니다.

## ⚠️ 실수하기 쉬운 점

- 대문자 P, Y를 빠뜨리지 않습니다.
- 둘 다 0개인 경우도 두 개수가 같은 경우입니다.
