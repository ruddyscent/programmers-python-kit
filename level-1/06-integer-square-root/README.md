# 🧩 정수 제곱근 판별

- Programmers ID: 12934
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12934
- Level: 1
- Stage: Level 1 Core 06
- Prerequisites: 곱셈, 조건문, 정수 비교
- Core concepts: 제곱, 정수 제곱근, 표준 라이브러리

## 🎯 이 문제에서 배우는 것

같은 수를 두 번 곱한 제곱을 이해하고 주어진 수가 정수의 제곱인지 검사합니다.

## 🔎 문제 핵심

양의 정수 `n`이 어떤 정수의 제곱이면 그 정수보다 1 큰 수의 제곱을 돌려줍니다. 정수의 제곱이 아니라면 -1을 돌려줍니다.

## 💭 먼저 생각해 보기

작은 정사각형 타일 16개를 빈틈없이 정사각형으로 놓으면 한 줄에 몇 개가 놓일까요? 17개로도 같은 모양을 만들 수 있을까요?

## 🧪 예제 이해하기

`n = 16`이면 `4 * 4 = 16`이므로 다음 수 5의 제곱인 25를 돌려줍니다. `n = 17`이면 `4 * 4`와 `5 * 5` 사이이므로 -1입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

Python의 `math` 모듈은 수학 도구를 모아 둔 표준 라이브러리입니다. `isqrt(n)`은 제곱해도 `n`을 넘지 않는 가장 큰 정수를 구합니다. 그 정수를 다시 제곱하여 `n`과 같은지 확인합니다.

### 🐍 Python 코드

```python
from math import isqrt


def solution(n):
    root = isqrt(n)
    if root * root == n:
        return (root + 1) * (root + 1)
    return -1
```

### 📖 코드 해설

`from math import isqrt`는 `math`에서 `isqrt` 함수를 가져오는 문장입니다. 따로 설치할 패키지는 없습니다. `isqrt(16)`과 `isqrt(17)`은 모두 4이므로 제곱해서 원래 수와 같은지 검사하는 줄이 꼭 필요합니다. 소수로 근삿값을 만들지 않고 정수로 계산합니다. [Python 문서](https://docs.python.org/3/library/math.html#math.isqrt)에서 함수의 뜻을 확인할 수 있습니다.

### ⏱️ 시간 복잡도

이 문제의 정수는 컴퓨터가 고정된 크기로 다룰 수 있는 범위인 64비트 안에 들어갑니다. 이 범위의 정수 제곱근과 곱셈을 고정 크기 연산으로 세면 시간은 `O(1)`입니다. 자릿수가 끝없이 늘어나는 정수까지 같은 시간이 걸린다는 뜻은 아닙니다.

### 💾 공간 복잡도

문제의 정수 범위에서 `root`와 반환값 등 몇 개의 수만 저장하므로 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `root`가 아니라 `root + 1`의 제곱을 반환합니다.
- `isqrt(n)`의 결과가 정수라는 이유만으로 `n`을 제곱수라고 판단하지 않습니다.

## ✅ 배운 것

정수 제곱근을 구한 뒤 다시 곱하면 제곱수인지 확인할 수 있습니다.
