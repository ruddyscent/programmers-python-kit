# 🧩 최대공약수와 최소공배수

- Programmers ID: 12940
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12940
- Level: 1
- Stage: Level 1 Core 10
- Prerequisites: 03 약수의 합, `%`, `min()`, 누적 갱신
- Core concepts: 공약수, 공배수, 나머지로 문제 줄이기

## 🎯 이 문제에서 배우는 것

두 수가 함께 나누어 떨어지는 수를 찾고 최대공약수와 최소공배수의 관계를 익힙니다.

## 🔎 문제 핵심

두 양의 정수 `n`, `m`의 최대공약수와 최소공배수를 이 순서대로 리스트에 담습니다. 최대공약수는 공통 약수 중 가장 큰 수, 최소공배수는 공통인 양의 배수 중 가장 작은 수입니다.

## 💭 먼저 생각해 보기

8의 약수와 12의 약수를 각각 적고 공통인 수를 동그라미 쳐 보세요. 이번에는 8의 배수와 12의 배수를 적어 처음 겹치는 수를 찾아보세요.

## 🧪 예제 이해하기

8과 12의 공약수는 1, 2, 4이므로 최대공약수는 4입니다. 양의 배수 중 처음 겹치는 수는 24이므로 결과는 `[4, 24]`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1부터 두 수 중 작은 수까지 확인합니다. 둘 다 나누어 떨어지면 최대공약수 후보를 갱신합니다. 마지막 후보가 가장 큽니다. 최소공배수는 두 수의 곱을 최대공약수로 나누어 구합니다.

### 🐍 Python 코드

```python
def solution(n, m):
    greatest_divisor = 1
    for divisor in range(1, min(n, m) + 1):
        if n % divisor == 0 and m % divisor == 0:
            greatest_divisor = divisor

    least_multiple = n * m // greatest_divisor
    return [greatest_divisor, least_multiple]
```

### 📖 코드 해설

`and` 양쪽의 나머지가 모두 0이어야 공약수입니다. 작은 후보부터 덮어쓰므로 마지막에는 가장 큰 공약수가 남습니다. 예에서 8과 12는 각각 `4 × 2`, `4 × 3`입니다. 공통 묶음 4를 한 번만 써서 `4 × 2 × 3 = 24`를 만들면 최소공배수가 됩니다. `8 × 12`에는 공통 묶음 4가 두 번 들어가므로 4로 한 번 나눕니다.

### ⏱️ 시간 복잡도

작은 입력을 `k = min(n, m)`이라고 하면 후보를 `k`번 확인하므로 `O(k)`입니다.

### 💾 공간 복잡도

몇 개의 수와 길이 2인 결과 리스트만 만듭니다. 반환 리스트를 포함한 추가 공간은 `O(1)`입니다.

## ✨ 풀이 2. 유클리드 호제법으로 반복 줄이기

### 💡 아이디어

두 수의 최대공약수는 큰 수를 작은 수로 나눈 나머지와 작은 수의 최대공약수와 같습니다. 예를 들어 `12 = 8 × 1 + 4`입니다. 12와 8을 모두 나누는 수는 4도 나누고, 8과 4를 모두 나누는 수는 12도 나눕니다. 공약수가 그대로라 더 작은 두 수로 바꿀 수 있습니다.

### 🐍 Python 코드

```python
def solution(n, m):
    first = max(n, m)
    second = min(n, m)
    while second != 0:
        remainder = first % second
        first = second
        second = remainder

    greatest_divisor = first
    least_multiple = n * m // greatest_divisor
    return [greatest_divisor, least_multiple]
```

### 📖 코드 해설

`(12, 8)`은 `(8, 4)`, 이어서 `(4, 0)`이 됩니다. 나머지가 0이면 마지막으로 나눈 수 4가 최대공약수입니다. `remainder`에 먼저 저장해야 `first`를 바꾸기 전의 나머지를 잃지 않습니다. 이 방법을 유클리드 호제법이라고 합니다. 이름보다 수가 줄어드는 과정을 먼저 따라가 보세요.

### ⏱️ 시간 복잡도

`k = min(n, m)`이라 할 때 작은 수는 늦어도 두 번의 반복 안에 절반보다 작아집니다. 반복 횟수는 `O(log k)`이며 `k = 1`은 일정한 계산으로 끝납니다.

### 💾 공간 복잡도

입력을 복사한 두 수와 나머지만 저장합니다. 반환 리스트를 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 공약수는 두 조건을 모두 만족해야 합니다. `or`가 아니라 `and`입니다.
- 반환 순서는 최대공약수, 최소공배수입니다.
- 최소공배수 계산에는 `/` 대신 `//`를 써서 정수를 유지합니다.
