# 🧩 제일 작은 수 제거하기

- Programmers ID: 12935
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12935
- Level: 1
- Stage: Level 1 Core 17
- Prerequisites: 리스트, `min()`, 순회, `append()`
- Core concepts: 순서 보존, 빈 결과 처리

## 🎯 이 문제에서 배우는 것

값 하나를 제외하면서 남은 값들의 원래 순서를 유지합니다.

## 🔎 문제 핵심

서로 다른 정수가 들어 있는 리스트 `arr`에서 최솟값을 뺀 리스트를 돌려줍니다. 남는 값이 없으면 `[-1]`을 돌려줍니다.

## 💭 먼저 생각해 보기

`[7, 2, 9, 4]`에서 가장 작은 값만 지워 보세요. 남은 값도 크기순으로 다시 놓아야 할까요?

## 🧪 예제 이해하기

`arr = [7, 2, 9, 4]`에서 2를 빼면 `[7, 9, 4]`입니다. `[6]`에서는 6을 빼고 나면 아무것도 없으므로 `[-1]`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

원소가 하나인 경우 먼저 처리합니다. 그 외에는 최솟값을 한 번 구하고 최솟값이 아닌 원소만 새 리스트에 담습니다.

### 🐍 Python 코드

```python
def solution(arr):
    if len(arr) == 1:
        return [-1]

    smallest = min(arr)
    remaining = []
    for number in arr:
        if number != smallest:
            remaining.append(number)
    return remaining
```

### 📖 코드 해설

`min(arr)`를 반복문 밖에서 한 번만 구합니다. 원소를 앞에서부터 읽어 새 리스트에 담으므로 순서가 유지됩니다. 이 문제는 원소가 서로 다르므로 최솟값도 하나뿐입니다. 입력 리스트 자체는 바꾸지 않습니다.

### ⏱️ 시간 복잡도

원소 개수를 `n`이라 하면 최솟값 찾기와 리스트 순회가 각각 `O(n)`입니다. 전체 시간은 `O(n)`입니다.

### 💾 공간 복잡도

반환할 새 리스트에 최대 `n - 1`개의 원소를 담으므로 반환값을 포함한 추가 공간은 `O(n)`입니다. 결과 리스트를 제외하면 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 정렬한 뒤 첫 값을 지우면 남은 원소들의 순서가 달라집니다.
- 반복문 안에서 매번 `min(arr)`를 호출하면 같은 탐색을 되풀이합니다.
- `arr.remove(...)`로 입력을 직접 바꾸는 방법과 이 풀이의 차이를 구별합니다.

## ✅ 배운 것

원래 순서대로 읽으면서 필요한 값만 새 리스트에 담으면 입력을 바꾸지 않아도 됩니다.
