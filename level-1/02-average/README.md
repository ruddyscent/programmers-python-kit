# 🧩 평균 구하기

- Programmers ID: 12944
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12944
- Level: 1
- Stage: Level 1 Core 02
- Prerequisites: 리스트, `for`, 합계 누적, `len()`, 나눗셈
- Core concepts: 합계와 개수, 평균

## 🎯 이 문제에서 배우는 것

리스트의 합계와 원소 개수를 따로 구한 뒤 평균을 계산합니다.

## 🔎 문제 핵심

정수 리스트 `arr`의 평균을 수로 돌려줍니다. 리스트에는 적어도 한 개의 수가 있고, 음수도 들어갈 수 있습니다.

## 💭 먼저 생각해 보기

점수가 2점, 5점, 8점인 세 번의 결과를 같은 점수로 나눈다면 각각 몇 점일까요? 먼저 합계와 개수를 적어 보세요.

## 🧪 예제 이해하기

`arr = [2, 5, 8]`이면 합계는 15, 개수는 3입니다. 평균은 `15 / 3`인 `5.0`입니다. `[2, 5]`의 평균은 `3.5`이므로 소수 부분을 버리면 안 됩니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

합계를 0에서 시작해 원소를 하나씩 더합니다. 모두 더한 뒤 리스트의 길이로 나눕니다.

### 🐍 Python 코드

```python
def solution(arr):
    total = 0
    for number in arr:
        total += number
    return total / len(arr)
```

### 📖 코드 해설

`total += number`는 `total = total + number`를 줄여 쓴 표현입니다. `len(arr)`는 원소 개수이고 `/`는 소수 부분을 남기는 나눗셈입니다. 입력 리스트는 바꾸지 않습니다.

### ⏱️ 시간 복잡도

원소 개수를 `n`이라고 하면 덧셈을 `n`번 합니다. `len(arr)`는 저장된 길이를 읽으므로 `O(1)`이고 전체 시간은 `O(n)`입니다.

### 💾 공간 복잡도

합계와 현재 수만 저장합니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ✨ 풀이 2. `sum()`으로 합계의 뜻 드러내기

### 💡 아이디어

합계를 구하는 반복문 대신 내장 함수 `sum()`을 씁니다.

### 🐍 Python 코드

```python
def solution(arr):
    return sum(arr) / len(arr)
```

### 📖 코드 해설

`sum(arr)`는 원소를 모두 더합니다. 계산 과정은 첫 풀이와 같고 코드에서 합계를 구한다는 뜻을 바로 읽을 수 있습니다.

### ⏱️ 시간 복잡도

원소 개수 `n`에 대해 `sum()`이 각 원소를 확인하므로 `O(n)`입니다.

### 💾 공간 복잡도

리스트를 복사하지 않습니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `//`를 쓰면 평균의 소수 부분이 사라집니다.
- `return`을 반복문 안에 넣으면 첫 원소만 더하고 함수가 끝납니다.

## ✅ 배운 것

평균은 합계를 개수로 나눈 값입니다. 합계 누적은 반복문으로도, `sum()`으로도 표현할 수 있습니다.
