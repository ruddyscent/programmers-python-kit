[Python Prep](../prep/README.md)에서 배운 문법으로 문제의 조건을 코드로 옮기는 단계입니다. 숫자와 반복, 숫자의 성질, 문자열, 리스트와 정렬, 문제 해결 패턴 순서로 25문제를 공부합니다.

## 🧭 학습 방법

1. 공식 문제를 읽고 입력과 결과를 자기 말로 설명합니다.
2. 작은 예를 손으로 풀고 코드를 쓰기 전에 해결 순서를 말해 보세요.
3. README의 풀이와 `solution.py`를 열기 전에 먼저 작성해 봅니다.
4. 막힌 부분을 학습자료에서 확인하고 도움받은 내용을 기록합니다.
5. 채점을 통과한 뒤 1주일 후 힌트 없이 다시 풀고 문제별 복습 항목을 확인합니다.

두 번째 풀이는 다른 표현이나 계산 방법을 비교할 때만 제공합니다. 제출용 `solution.py`는 각 README의 첫 풀이와 같습니다. 끝의 추가 연습은 처음부터 모두 풀 필요는 없습니다. 배운 개념을 다시 쓰고 싶을 때 골라 보세요.

## ⏱️ 복잡도 읽는 법

시간 복잡도는 입력이 커질 때 계산량이 얼마나 늘어나는지, 공간 복잡도는 추가로 저장할 자료가 얼마나 늘어나는지 나타냅니다. `n`은 보통 원소 개수지만 문제마다 뜻이 다르므로 각 설명의 정의를 먼저 읽으세요. 실행 시간을 초 단위로 예측하는 표시는 아닙니다.

| 표기 | 읽는 방법 | 이 단계의 예 |
|---|---|---|
| `O(1)` | 입력 크기와 관계없이 일정한 작업 | 짝수 여부 검사 |
| `O(n)` | 원소 수에 비례하는 작업 | 모든 원소 더하기 |
| `O(log n)` | 범위를 계속 줄이는 작업 | 나머지로 최대공약수 구하기 |
| `O(n log n)` | 비교 정렬에서 보는 작업량 | 숫자 정렬 |
| `O(n²)` | 원소들의 쌍을 살피는 작업량 | 두 수를 고르는 중첩 반복 |

`log n`은 반으로 줄이는 일을 몇 번 해야 하는지와 연결해 생각하세요. 8에서 시작하면 4, 2, 1로 세 번 줄입니다. `O(n log n)`은 이런 단계 수에 원소 수를 곱한 정도의 작업량입니다. 지금은 표기를 외우기보다 설명된 반복과 저장 공간을 찾아보면 됩니다.

수의 덧셈·곱셈·나머지는 문제에서 쓰는 크기에서는 한 번의 연산으로 셉니다. 아주 긴 정수의 자릿수별 계산 비용까지 다루지는 않습니다. 공간 설명은 입력 자체를 제외하고 반환값은 포함합니다. 정렬이나 슬라이싱으로 생긴 복사본도 셉니다.

개인 학습용 복사본에서 각 문제 README의 `- [ ]`를 `- [x]`로 바꾸어 기록할 수 있습니다. 직접 채점을 통과하고, 1주일 뒤 힌트 없이 다시 풀고, 풀이를 말로 설명했다면 완료로 셉니다. 이 단계의 완료 수와 [전체 진도표](../README.md)의 Core·합계 숫자를 함께 수정하세요. 숫자는 자동으로 집계되지 않습니다. 풀이를 보고 해결한 날은 독립 완료로 세지 말고 혼자 다시 풀었을 때 기록합니다.

- [ ] 반복문이 어디서 시작하고 끝나는지 설명하기
