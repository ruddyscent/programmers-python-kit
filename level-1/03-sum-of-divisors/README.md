# 🧩 약수의 합

- Programmers ID: 12928
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12928
- Level: 1
- Stage: Level 1 Core 03
- Prerequisites: `for`, `range()`, `%`, 조건문
- Core concepts: 약수, 조건에 맞는 값의 누적합

## 🎯 이 문제에서 배우는 것

약수가 무엇인지 나머지와 연결하고 조건에 맞는 수만 더합니다.

## 🔎 문제 핵심

입력 `n`의 양의 약수를 더해 돌려줍니다. 약수는 어떤 수를 나누었을 때 나머지가 0이 되는 수입니다. 이 문제에서 `n = 0`은 합계 0으로 처리합니다.

## 💭 먼저 생각해 보기

구슬 8개를 한 줄에 같은 개수씩 놓으려 합니다. 한 줄에 1개부터 8개까지 놓아 보며 남는 구슬이 없는 경우를 찾아보세요.

## 🧪 예제 이해하기

`n = 8`일 때 약수는 1, 2, 4, 8입니다. 합계는 `1 + 2 + 4 + 8 = 15`입니다. 3으로 나누면 2가 남으므로 3은 더하지 않습니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1부터 `n`까지 차례대로 확인합니다. `n`을 현재 수로 나눈 나머지가 0일 때만 합계에 더합니다.

### 🐍 Python 코드

```python
def solution(n):
    total = 0
    for divisor in range(1, n + 1):
        if n % divisor == 0:
            total += divisor
    return total
```

### 📖 코드 해설

`range(1, n + 1)`의 끝값은 포함되지 않으므로 마지막으로 확인하는 수는 `n`입니다. 0으로 나눌 수 없어서 시작값은 1입니다. `n = 0`이면 반복할 수가 없으므로 처음 합계 0을 그대로 반환합니다.

### ⏱️ 시간 복잡도

입력값 `n`에 대해 후보를 `n`개 확인하므로 양수 입력에서는 `O(n)`입니다. `n = 0`이면 반복 없이 끝납니다.

### 💾 공간 복잡도

약수 목록을 따로 만들지 않고 합계만 갱신합니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 1과 자기 자신도 약수입니다. 반복 범위에서 빠뜨리지 않습니다.
- 0의 모든 약수를 구한다는 뜻으로 해석하지 않습니다. 이 문제의 0 입력은 합계 0으로 처리합니다.

## ✅ 배운 것

반복문 안에서 조건을 검사하면 필요한 값만 누적할 수 있습니다.
