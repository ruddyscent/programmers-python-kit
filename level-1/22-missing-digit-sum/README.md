# 🧩 없는 숫자 더하기

- Programmers ID: 86051
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/86051
- Level: 1
- Stage: Level 1 Core 22
- Prerequisites: `range()`, `in`, `not in`, 합계 누적
- Core concepts: 전체 후보와 주어진 값 비교

## 🎯 이 문제에서 배우는 것

주어진 값만 읽는 대신 전체 후보를 확인하며 빠진 값을 찾습니다.

## 🔎 문제 핵심

0부터 9까지의 숫자 중 `numbers`에 들어 있지 않은 숫자를 모두 더합니다. 입력 리스트의 값은 서로 다릅니다.

## 💭 먼저 생각해 보기

0부터 9까지 적고 입력 `[0, 2, 4, 6, 8]`에 있는 수를 지워 보세요. 남아 있는 수는 무엇인가요?

## 🧪 예제 이해하기

`numbers = [0, 2, 4, 6, 8]`에 없는 숫자는 1, 3, 5, 7, 9입니다. 결과는 `1 + 3 + 5 + 7 + 9 = 25`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

전체 후보인 0부터 9까지 차례로 확인합니다. 입력 리스트에 없는 후보만 합계에 더합니다.

### 🐍 Python 코드

```python
def solution(numbers):
    total = 0
    for digit in range(10):
        if digit not in numbers:
            total += digit
    return total
```

### 📖 코드 해설

`range(10)`은 0부터 9까지입니다. `digit not in numbers`는 리스트에서 그 수를 찾을 수 없으면 참입니다. 입력 리스트가 정렬되어 있을 필요는 없습니다. 여기서는 집합을 만들지 않고 리스트에서 직접 찾습니다.

### ⏱️ 시간 복잡도

입력 원소 수를 `n`이라고 하면 리스트에서 한 숫자를 찾는 데 최악 `O(n)`이 듭니다. 이를 10번 하므로 `O(10n)`, 즉 `O(n)`입니다. 실제 문제에서는 `n`도 최대 9로 제한됩니다.

### 💾 공간 복잡도

후보와 합계만 저장하므로 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ✨ 풀이 2. 전체 합에서 있는 숫자의 합 빼기

### 💡 아이디어

0부터 9까지의 합은 45입니다. 모든 수의 합에서 입력에 있는 수의 합을 빼면 없는 수의 합이 남습니다.

### 🐍 Python 코드

```python
def solution(numbers):
    return 45 - sum(numbers)
```

### 📖 코드 해설

입력의 수가 서로 다르다는 조건이 중요합니다. 같은 숫자가 두 번 들어갈 수 있다면 두 번 빼게 되므로 이 공식을 그대로 쓸 수 없습니다. 첫 풀이처럼 열 번 검색하는 대신 합계를 한 번 구합니다.

### ⏱️ 시간 복잡도

입력 원소 수 `n`에 대해 `sum(numbers)`가 한 번 순회하므로 `O(n)`입니다. 첫 풀이와 Big O 표기는 같지만 리스트를 반복 검색하지 않습니다.

### 💾 공간 복잡도

반환값과 합계 외에 자료를 만들지 않으므로 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 입력에 있는 수의 합이 아니라 없는 수의 합을 구합니다.
- `range(1, 9)`는 0과 9를 모두 빠뜨립니다.

## ✅ 배운 것

전체 후보의 범위를 알면 주어진 자료와 비교해 빠진 값을 찾을 수 있습니다.
