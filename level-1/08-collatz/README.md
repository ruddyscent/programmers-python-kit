# 🧩 콜라츠 추측

- Programmers ID: 12943
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12943
- Level: 1
- Stage: Level 1 Core 08
- Prerequisites: 01 짝수와 홀수, `while`, `//`
- Core concepts: 값 갱신, 횟수 제한, 종료 조건

## 🎯 이 문제에서 배우는 것

반복할 때마다 수와 횟수를 함께 바꾸고 정해진 횟수 안에 목표에 도달했는지 확인합니다.

## 🔎 문제 핵심

입력 `num`이 짝수면 절반으로, 홀수면 세 배에 1을 더한 수로 바꿉니다. 1이 되기까지 바꾼 횟수를 돌려주되, 500번 바꾼 뒤에도 1이 아니면 -1입니다. 처음부터 1이면 0번입니다.

## 💭 먼저 생각해 보기

4에서 시작해 수가 바뀔 때마다 화살표를 그려 보세요. 수를 몇 개 적었는지와 화살표를 몇 개 그렸는지는 같을까요?

## 🧪 예제 이해하기

4에서 시작하면 아래처럼 두 번 바꿉니다. 처음의 4는 작업 결과가 아니므로 횟수에 넣지 않습니다.

```text
수:    4 -> 2 -> 1
횟수:  0    1    2
```

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

현재 수가 1이 아니고 작업 횟수도 500보다 작은 동안 반복합니다. 한 번 바꿀 때마다 횟수를 1 늘리고 반복이 끝난 이유를 마지막 조건문에서 확인합니다.

### 🐍 Python 코드

```python
def solution(num):
    steps = 0
    while num != 1 and steps < 500:
        if num % 2 == 0:
            num //= 2
        else:
            num = num * 3 + 1
        steps += 1

    if num == 1:
        return steps
    return -1
```

### 📖 코드 해설

`and`로 연결한 두 조건은 모두 참이어야 합니다. `num //= 2`는 `num = num // 2`와 같습니다. 짝수는 정수 나눗셈으로 정확히 절반이 됩니다. 반복이 끝나도 `num == 1`을 다시 검사하므로 마지막 허용 작업에서 1이 된 경우까지 셉니다.

### ⏱️ 시간 복잡도

실제로 수행한 작업 수를 `t`라고 하면 `O(t)`입니다. 이 문제에서는 `t`가 최대 500이므로 고정된 횟수 제한으로 보면 `O(1)`입니다. 수의 계산은 문제 범위에서 한 번의 연산으로 셉니다.

### 💾 공간 복잡도

중간 수를 모두 모으지 않고 현재 수와 횟수만 저장합니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 처음부터 1이면 반복문에 들어가지 않아야 합니다.
- 횟수만 보고 -1을 반환하지 말고 마지막 수가 1인지 확인합니다.
- `steps += 1`은 홀수와 짝수 두 경우 모두 실행되어야 합니다.

## ✅ 배운 것

`while`에는 계속할 조건과 언젠가 멈추게 하는 값의 변화가 필요합니다.
