## 🧭 혼자 풀어보기

1. 공식 링크에서 문제를 읽고 입력과 결과를 자기 말로 적습니다.
2. 작은 예를 손으로 풀어 봅니다.
3. 코드를 작성하기 전에 해결 방법을 말로 설명합니다.
4. 이전 풀이와 풀이 검색 없이 직접 작성합니다. Python 문법은 찾아봐도 됩니다.
5. 채점 결과를 확인한 뒤 자신이 작성한 코드를 이 폴더의 `solution.py`에 저장합니다.

이 자료에는 정답 코드와 알고리즘 힌트가 없습니다. 독립 시도 후 풀이를 요청했다면, 복습 해설은 별도 파일에 두어 처음 연습하는 화면과 구분합니다.
