# 🏁 Level 1 Checkpoint

[Core 25문제](../README.md)를 공부한 뒤 혼자 해결하는 연습입니다. 아래 다섯 문제는 정답이나 알고리즘 힌트 없이 시작합니다.

## 🧭 연습 규칙

1. 이전 풀이를 보거나 문제 풀이를 검색하지 않습니다. Python 문법은 찾아봐도 됩니다.
2. 공식 문제를 읽고 작은 예를 손으로 풀어 봅니다.
3. 코드를 쓰기 전에 자신의 해결 방법을 말로 설명합니다.
4. 직접 코드를 작성하고 프로그래머스에서 채점합니다.
5. 막힌 부분과 도움받은 내용을 솔직하게 기록합니다. 도움을 받아 해결했다면 독립 통과로 세지 않습니다.

## ✅ 완료 확인

독립 연습 안내는 5문제 모두 준비되어 있습니다. 해설과 `solution.py`는 제공하지 않으며 확인된 독립 풀이 완료는 0문제입니다. 직접 시도한 뒤 자신의 코드를 각 폴더에 저장하세요.

개인 학습용 복사본에서 문제별 체크리스트의 `- [ ]`를 `- [x]`로 바꾸어 기록합니다. 도움 없이 작성해 채점을 통과하고, 1주일 뒤 다시 풀고, 풀이를 설명했다면 완료로 셉니다. 이 페이지의 완료 수와 [전체 진도표](../../README.md)의 Checkpoint·합계 숫자를 직접 갱신하세요.

다섯 문제를 모두 힌트 없이 해결한 뒤 프로그래머스 Skill Check Level 1에 도전합니다. 일부 문제를 도움받아 풀었다면 그 문제는 다시 혼자 시도해 보세요.
