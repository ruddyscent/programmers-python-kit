# 🧩 하샤드 수

- Programmers ID: 12947
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12947
- Level: 1
- Stage: Level 1 Core 07
- Prerequisites: 04 자릿수 더하기, `%`, 비교
- Core concepts: 계산 결과로 조건 검사하기

## 🎯 이 문제에서 배우는 것

자릿수 합을 구하는 과정과 나누어 떨어지는지 검사하는 과정을 연결합니다.

## 🔎 문제 핵심

양의 정수 `x`를 그 자릿수의 합으로 나누었을 때 나머지가 0이면 `True`, 아니면 `False`를 돌려줍니다. 이런 성질을 가진 수를 하샤드 수라고 부릅니다.

## 💭 먼저 생각해 보기

24의 두 숫자를 더한 값으로 24를 나누어 보세요. 25에 같은 과정을 해 보면 어떤 차이가 있나요?

## 🧪 예제 이해하기

24의 자릿수 합은 6이고 `24 % 6`은 0이므로 `True`입니다. 25의 자릿수 합은 7인데 `25 % 7`은 4이므로 `False`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

각 숫자를 더해 `digit_sum`에 저장합니다. 마지막에는 원래 수 `x`를 `digit_sum`으로 나눈 나머지를 검사합니다.

### 🐍 Python 코드

```python
def solution(x):
    digit_sum = 0
    for character in str(x):
        digit_sum += int(character)
    return x % digit_sum == 0
```

### 📖 코드 해설

`x % digit_sum == 0` 자체가 참 또는 거짓을 나타내는 값입니다. 그래서 `if`로 다시 나누지 않고 바로 반환할 수 있습니다. 입력은 양수라 자릿수 합도 1 이상입니다. 이 풀이에서는 원래 `x`를 다른 값으로 바꾸지 않습니다.

### ⏱️ 시간 복잡도

자릿수를 `d`라고 하면 문제 범위에서 문자열 변환과 각 자리 확인에 `O(d)`의 시간이 듭니다.

### 💾 공간 복잡도

`str(x)`로 길이 `d`인 문자열을 만듭니다. 반환값을 포함한 추가 공간은 `O(d)`입니다.

## ⚠️ 실수하기 쉬운 점

- `True`와 `False`에는 따옴표를 붙이지 않습니다. 문자열이 아니라 참·거짓 값입니다.
- 합계가 원래 수를 나누는지 확인합니다. 나누는 순서를 뒤집지 않습니다.
