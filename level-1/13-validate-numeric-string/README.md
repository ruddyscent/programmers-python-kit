# 🧩 문자열 다루기 기본

- Programmers ID: 12918
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12918
- Level: 1
- Stage: Level 1 Core 13
- Prerequisites: `len()`, 조건문, `and`, 문자열 순회
- Core concepts: 여러 조건 검사, 조기 반환

## 🎯 이 문제에서 배우는 것

길이 조건과 글자 조건을 나누어 검사하고 조건이 어긋나는 순간 끝냅니다.

## 🔎 문제 핵심

문자열 `s`는 길이가 4 또는 6이면서 모든 글자가 숫자여야 합니다. 두 조건을 모두 만족할 때만 `True`를 돌려줍니다.

## 💭 먼저 생각해 보기

`"5082"`, `"50a2"`, `"508"`를 비교해 보세요. 틀린 경우마다 길이와 글자 중 무엇이 조건에 맞지 않는지 말해 보세요.

## 🧪 예제 이해하기

`"5082"`는 길이 4이며 전부 숫자라 `True`입니다. `"50a2"`는 a 때문에 `False`, `"508"`은 길이가 3이라 `False`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

길이가 4도 아니고 6도 아니면 바로 거짓을 반환합니다. 길이가 맞으면 한 글자씩 확인하고 숫자가 아닌 글자를 발견할 때 거짓을 반환합니다. 끝까지 통과해야 참입니다.

`and`는 두 조건이 모두 참일 때, `or`는 둘 중 하나라도 참일 때 참이 됩니다. 여기서는 길이가 4가 아니라는 조건과 6이 아니라는 조건을 모두 만족해야 거절하므로 `and`로 연결합니다.

### 🐍 Python 코드

```python
def solution(s):
    if len(s) != 4 and len(s) != 6:
        return False

    for character in s:
        if character not in "0123456789":
            return False
    return True
```

### 📖 코드 해설

`not in`은 그 안에 없다는 뜻입니다. 숫자 문자 열 개에 현재 글자가 없으면 검사에 실패합니다. 마지막 `return True`는 반복문 밖에 있어야 모든 글자를 검사한 뒤 실행됩니다.

### ⏱️ 시간 복잡도

문자열 길이를 `n`이라고 하겠습니다. 글자마다 길이 10인 고정 문자열을 확인하므로 글자 하나의 검사는 `O(1)`, 전체 순회는 `O(n)`입니다. 실제로는 길이가 4나 6일 때만 순회하므로 이 문제의 검사 횟수는 상수로 제한됩니다.

### 💾 공간 복잡도

검사용 숫자 문자열은 길이가 10으로 일정합니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 거절 조건에 `or`를 쓰면 길이 4도 길이 6도 거절됩니다. 길이 4는 6이 아니기 때문입니다.
- 한 글자가 숫자라는 이유만으로 `True`를 반환하지 않습니다.

## ✅ 배운 것

실패한 조건에서는 바로 끝낼 수 있지만 성공은 모든 조건을 확인한 뒤 판단해야 합니다.
