# 🧩 두 개 뽑아서 더하기

- Programmers ID: 68644
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/68644
- Level: 1
- Stage: Level 1 Core 21
- Prerequisites: 리스트 인덱싱, `range()`, `for`, `sorted()`
- Core concepts: 서로 다른 위치의 쌍, 집합 `set`

## 🎯 이 문제에서 배우는 것

서로 다른 두 위치를 빠짐없이 고르고 같은 합계는 한 번만 남깁니다.

## 🔎 문제 핵심

리스트 `numbers`의 서로 다른 위치 두 곳에서 수를 골라 더합니다. 만들 수 있는 합을 중복 없이 작은 순서로 돌려줍니다. 값이 같아도 위치가 다르면 고를 수 있습니다.

## 💭 먼저 생각해 보기

`[2, 2, 5]`에서 각 수 아래에 0, 1, 2를 적어 보세요. 같은 값 2 두 개를 고르는 것과 같은 위치를 두 번 고르는 것은 어떻게 다를까요?

## 🧪 예제 이해하기

위치 `(0, 1)`의 합은 4, `(0, 2)`와 `(1, 2)`의 합은 각각 7입니다. 합 7은 한 번만 남기므로 결과는 `[4, 7]`입니다.

```text
첫 위치 -> 함께 고를 뒤쪽 위치
   0    -> 1, 2
   1    -> 2
   2    -> 없음
```

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

첫 위치를 정한 뒤 두 번째 위치는 그 뒤에서만 고릅니다. 합은 집합에 넣습니다. 집합 `set`은 같은 값을 다시 넣어도 하나만 보관하는 자료형입니다. 마지막에 정렬해서 리스트로 바꿉니다.

### 🐍 Python 코드

```python
def solution(numbers):
    sums = set()
    for first in range(len(numbers)):
        for second in range(first + 1, len(numbers)):
            sums.add(numbers[first] + numbers[second])
    return sorted(sums)
```

### 📖 코드 해설

반복문 안에 반복문이 있는 것을 중첩 반복이라고 합니다. `first` 하나마다 `second`가 뒤쪽 위치들을 차례로 확인합니다. 이렇게 하면 같은 위치를 두 번 고르지 않고 `(0, 1)`과 `(1, 0)`을 중복으로 살피지도 않습니다. 빈 집합은 `set()`으로 만듭니다. `sums.add(value)`는 값을 넣으며 집합에는 정렬 순서가 없으므로 `sorted()`로 마무리합니다.

### ⏱️ 시간 복잡도

원소 수를 `n`, 서로 다른 합의 수를 `k`라고 하겠습니다. 쌍은 `n(n - 1) / 2`개입니다. 집합에 넣기를 평균 `O(1)`로 세면 전체 시간은 평균적으로 `O(n² + k log k)`입니다. 이 문제의 수는 0부터 100이라 합의 종류도 최대 201개입니다.

### 💾 공간 복잡도

집합과 정렬된 반환 리스트, 정렬용 임시 공간에 `O(k)`를 씁니다. 반환값을 포함한 추가 공간이며 모든 쌍을 별도의 리스트에 저장하지 않습니다.

## ⚠️ 실수하기 쉬운 점

- `second`를 0부터 시작하면 같은 위치를 고르거나 같은 쌍을 다시 보게 됩니다.
- 입력에서 중복된 값을 지우면 안 됩니다. 위치가 다른 같은 수 둘도 한 쌍입니다.
- `{}`는 빈 집합이 아닙니다. 빈 집합은 `set()`으로 만듭니다.

## ✅ 배운 것

위치는 구별하고 결과값의 중복은 없애야 합니다. 이 문제에서 리스트와 집합의 역할이 다릅니다.
