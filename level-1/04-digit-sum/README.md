# 🧩 자릿수 더하기

- Programmers ID: 12931
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12931
- Level: 1
- Stage: Level 1 Core 04
- Prerequisites: 문자열, `for`, `int()`, 합계 누적
- Core concepts: 정수와 문자열 변환, 자릿수

## 🎯 이 문제에서 배우는 것

하나의 정수를 글자들로 나누어 살펴보고 각 글자를 다시 수로 바꿔 더합니다.

## 🔎 문제 핵심

자연수 `n`의 각 자리에 있는 숫자를 모두 더한 정수를 돌려줍니다. 자릿수의 개수가 아니라 각 숫자의 합이 필요합니다.

## 💭 먼저 생각해 보기

숫자 405를 종이에 크게 적고 한 자리씩 잘라 보세요. 세 조각에 적힌 수를 더하면 얼마일까요?

## 🧪 예제 이해하기

`n = 405`를 문자열로 바꾸면 `"405"`입니다. `"4"`, `"0"`, `"5"`를 정수로 바꿔 더하면 `4 + 0 + 5 = 9`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

`str(n)`으로 숫자를 문자열로 바꿉니다. 글자를 하나씩 꺼내 `int()`로 변환한 뒤 합계에 더합니다.

### 🐍 Python 코드

```python
def solution(n):
    total = 0
    for character in str(n):
        total += int(character)
    return total
```

### 📖 코드 해설

`str()`은 값을 문자열로 바꾸는 내장 함수입니다. 정수 405 자체를 `for`로 순회할 수는 없지만 문자열 `"405"`는 글자별로 읽을 수 있습니다. `int(character)`가 없으면 문자열과 정수를 더하려 하므로 오류가 납니다.

### ⏱️ 시간 복잡도

십진수 자릿수를 `d`라고 하겠습니다. 문제 범위에서 문자열 변환과 `d`개 글자 확인에 드는 시간을 자릿수에 비례하는 것으로 세면 `O(d)`입니다.

### 💾 공간 복잡도

`str(n)`으로 만든 문자열이 `d`칸을 차지합니다. 반환값을 포함한 추가 공간은 `O(d)`입니다.

## ⚠️ 실수하기 쉬운 점

- `len(str(n))`은 숫자의 합이 아니라 자릿수 개수입니다.
- 가운데 0도 하나의 자리입니다. 더하면 합계는 그대로입니다.

## ✅ 배운 것

숫자를 글자별로 읽고 싶을 때 `str()`을, 숫자 문자를 계산하고 싶을 때 `int()`를 씁니다.
