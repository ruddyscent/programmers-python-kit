# 🧩 자연수 뒤집어 배열로 만들기

- Programmers ID: 12932
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12932
- Level: 1
- Stage: Level 1 Core 16
- Prerequisites: 04 자릿수 더하기, 리스트, `append()`, 슬라이싱
- Core concepts: 자릿수 순서, 문자열에서 리스트로 변환

## 🎯 이 문제에서 배우는 것

각 자리 숫자를 거꾸로 읽고 정수 리스트에 차례로 담습니다.

## 🔎 문제 핵심

자연수 `n`의 오른쪽 자리부터 숫자를 하나씩 꺼낸 순서로 리스트를 돌려줍니다. 결과의 각 원소는 문자열이 아닌 정수여야 합니다.

## 💭 먼저 생각해 보기

숫자 7302를 오른쪽부터 읽어 보세요. 0도 한 칸을 차지한다는 점을 생각하며 빈 리스트에 무엇을 넣을지 적어 보세요.

## 🧪 예제 이해하기

`n = 7302`이면 오른쪽부터 2, 0, 3, 7이므로 결과는 `[2, 0, 3, 7]`입니다. 숫자를 내림차순으로 정렬하는 문제가 아닙니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

수를 문자열로 바꾸고 `[::-1]`로 뒤집습니다. 뒤집힌 문자열의 각 글자를 정수로 바꿔 리스트에 추가합니다.

### 🐍 Python 코드

```python
def solution(n):
    digits = []
    for character in str(n)[::-1]:
        digits.append(int(character))
    return digits
```

### 📖 코드 해설

슬라이싱 `[::-1]`의 마지막 -1은 뒤로 한 칸씩 이동하라는 뜻입니다. 따라서 `str(n)[::-1]`은 뒤집힌 새 문자열입니다. `digits.append()`는 읽은 숫자를 리스트 끝에 추가하므로 읽은 순서가 보존됩니다.

### ⏱️ 시간 복잡도

자릿수를 `d`라 하면 문제 범위에서 문자열 변환, 뒤집기, 리스트 만들기가 각각 `O(d)`입니다. 전체 시간도 `O(d)`입니다.

### 💾 공간 복잡도

원래 자릿수 문자열, 뒤집힌 문자열, 결과 리스트가 자릿수에 비례하는 공간을 씁니다. 반환 리스트를 포함한 추가 공간은 `O(d)`입니다.

## ⚠️ 실수하기 쉬운 점

- `sorted()`는 크기순으로 배치하므로 원래 자리의 역순과 다릅니다.
- `int()` 없이 글자를 추가하면 `"2"` 같은 문자열 원소가 들어갑니다.
- 끝에 0이 있는 수도 확인합니다. 120의 결과 맨 앞에는 0이 들어갑니다.
