# 🧩 두 정수 사이의 합

- Programmers ID: 12912
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12912
- Level: 1
- Stage: Level 1 Core 05
- Prerequisites: `range()`, `for`, `min()`, `max()`, 누적합
- Core concepts: 범위의 양 끝, 입력 순서

## 🎯 이 문제에서 배우는 것

입력 순서와 관계없이 범위를 정하고 양 끝을 포함해 더합니다.

## 🔎 문제 핵심

정수 `a`, `b`를 양 끝으로 하는 범위의 모든 정수를 더해 돌려줍니다. 두 입력의 크기 순서는 정해져 있지 않고, 같은 수가 들어올 수도 있습니다.

## 💭 먼저 생각해 보기

수직선에서 -2와 2 사이에 있는 정수를 모두 적어 보세요. 입력 순서가 2, -2로 바뀌어도 적은 수가 달라질까요?

## 🧪 예제 이해하기

`a = 2`, `b = -2`이면 더할 수는 -2, -1, 0, 1, 2입니다. 합계는 0입니다. 두 입력이 모두 6이면 6을 한 번만 더합니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

작은 값을 시작점, 큰 값을 끝점으로 정합니다. 끝점까지 포함하도록 `range()`의 두 번째 값에 1을 더합니다.

### 🐍 Python 코드

```python
def solution(a, b):
    start = min(a, b)
    end = max(a, b)
    total = 0
    for number in range(start, end + 1):
        total += number
    return total
```

### 📖 코드 해설

`min(a, b)`와 `max(a, b)`는 두 값 중 작은 값과 큰 값을 고릅니다. `range()`는 모든 수를 담은 리스트를 미리 만들지 않습니다. 범위가 넓을수록 반복 횟수는 늘어나므로 큰 입력에서는 아래 공식을 쓰는 방법도 비교해 보세요.

### ⏱️ 시간 복잡도

더하는 정수 개수를 `k = abs(a - b) + 1`이라고 하겠습니다. `abs()`는 부호를 뺀 크기를 구합니다. 반복문은 `k`번 실행하므로 `O(k)`입니다.

### 💾 공간 복잡도

합계와 범위 정보만 저장합니다. `range()`와 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ✨ 풀이 2. 반복 횟수를 줄이는 합 공식

### 💡 아이디어

앞뒤 수를 짝지으면 각 쌍의 합이 같습니다. 같은 수열을 앞뒤로 두 번 적으면 모든 자리의 합이 `start + end`가 됩니다. 그 합에 개수를 곱한 값은 원래 합의 두 배입니다.

### 🐍 Python 코드

```python
def solution(a, b):
    start = min(a, b)
    end = max(a, b)
    count = end - start + 1
    return (start + end) * count // 2
```

### 📖 코드 해설

4부터 6까지라면 `4 + 6`, `5 + 5`, `6 + 4`가 모두 10입니다. 두 줄의 합 30을 2로 나누면 15입니다. 곱한 뒤 `// 2`를 해야 합니다. 곱은 항상 짝수이므로 정수 결과를 얻습니다. 첫 풀이와 달리 범위 전체를 반복하지 않습니다.

### ⏱️ 시간 복잡도

문제 범위의 정수 연산을 한 번의 계산으로 세면 범위가 넓어져도 계산 횟수는 일정하므로 `O(1)`입니다.

### 💾 공간 복잡도

몇 개의 정수만 저장합니다. 반환값을 포함한 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `range(start, end)`는 끝의 수를 포함하지 않습니다.
