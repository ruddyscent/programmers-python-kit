## 🎯 이 문제에서 배우는 것

선택을 되돌릴 필요가 없는 이유를 설명하며 가장 적은 배를 사용합니다.

## 🔎 문제 핵심

한 배에 최대 두 명을 태우고 무게 합을 limit 이하로 제한할 때 people의 모든 사람을 옮기는 최소 배 수를 돌려줍니다.

## 💭 먼저 생각해 보기

[40, 50, 60, 70]과 limit = 100에서 70인 사람을 누구와 태울 수 있나요? 가장 가벼운 사람과도 못 탄다면 무엇이 확실해지나요?

## 🧪 예제 이해하기

70은 누구와도 같이 못 타서 혼자 갑니다. 40과 60은 함께, 50은 혼자라 총 3대입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

정렬된 양 끝을 가리킵니다. 가장 무거운 사람이 가장 가벼운 사람과 함께 탈 수 있으면 둘을 처리하고 아니면 무거운 사람만 처리합니다.

### 🐍 Python 코드

```python
def solution(people, limit):
    weights = sorted(people)
    light = 0
    heavy = len(weights) - 1
    boats = 0
    while light <= heavy:
        if light < heavy and weights[light] + weights[heavy] <= limit:
            light += 1
        heavy -= 1
        boats += 1
    return boats
```

### 📖 코드 해설

가장 가벼운 사람과도 못 타면 무거운 사람은 어떤 짝과도 못 타므로 혼자 보내야 합니다. 같이 탈 수 있다면 최적 배치의 짝을 바꾸어 둘을 함께 보내도 배 수가 늘지 않습니다. 둘이 다른 사람 x, y와 각각 타고 있었다면 남은 x, y를 함께 보낼 수 있습니다. y는 현재 가장 무거운 사람보다 무겁지 않으므로 x+y는 원래 x가 탔던 배의 합 이하입니다. 한 사람이 혼자였던 경우에는 남은 사람을 혼자 보내도 배 수가 늘지 않습니다. 이렇게 최적 답을 잃지 않는 선택을 반복하는 방법이 그리디입니다.

### ⏱️ 시간 복잡도

사람 수 N에 대해 정렬 O(N log N), 포인터 이동 O(N)이라 전체 O(N log N)입니다.

### 💾 공간 복잡도

정렬 복사본과 정렬용 임시 공간에 추가 공간 O(N)을 씁니다. 반환값 포함이며 입력은 보존합니다.

## ⚠️ 실수하기 쉬운 점

- 한 사람이 남았을 때 자기 자신과 무게를 더하지 않습니다.
- limit와 합이 같아도 같이 탈 수 있습니다.

## ✅ 배운 것

그리디는 유리해 보이는 선택만 하는 것이 아니라 그 선택이 최적 답을 잃지 않는지 확인해야 합니다.
