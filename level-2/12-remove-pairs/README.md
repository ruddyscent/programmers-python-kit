# 🧩 짝지어 제거하기

- Programmers ID: 12973
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12973
- Level: 2
- Stage: Level 2 Core 12
- Prerequisites: 11 올바른 괄호, 리스트 append()
- Core concepts: 스택, 마지막 항목 제거

## 🎯 이 문제에서 배우는 것

최근에 남은 글자만 확인해 새로 맞닿는 짝을 처리합니다.

## 🔎 문제 핵심

s에서 이웃한 같은 글자 두 개를 지우는 일을 반복합니다. 모두 지울 수 있으면 1, 남는 글자가 있으면 0을 돌려줍니다.

## 💭 먼저 생각해 보기

"abba"에서 가운데 bb를 지우면 어떤 글자끼리 새로 이웃이 되나요?

## 🧪 예제 이해하기

"abba"는 bb를 지우면 aa가 되고 다시 지우면 빈 문자열입니다. 결과는 1입니다. "abca"는 지울 짝이 없어 0입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

남은 글자를 리스트 끝에 쌓습니다. 새 글자가 끝의 글자와 같으면 끝 글자를 꺼내 둘을 지운 효과를 냅니다.

### 🐍 Python 코드

```python
def solution(s):
    stack = []
    for character in s:
        if stack and stack[-1] == character:
            stack.pop()
        else:
            stack.append(character)
    if len(stack) == 0:
        return 1
    return 0
```

### 📖 코드 해설

스택은 마지막에 넣은 값을 먼저 꺼내는 자료구조입니다. 리스트의 append()로 넣고 인자가 없는 pop()으로 끝 값을 꺼냅니다. stack이 빈 리스트면 조건에서 거짓이므로 stack[-1]을 읽지 않습니다. 지금까지 읽은 부분에서 지울 짝이 모두 처리되어 있어 새 글자는 끝의 글자만 확인하면 됩니다.

```text
읽은 글자: a  b  b  a
스택:     a  ab a  빈칸
```

### ⏱️ 시간 복잡도

길이 N의 글자를 한 번 읽으며 각 글자는 최대 한 번 들어가고 한 번 나옵니다. 리스트가 커질 때 가끔 복사가 일어나지만 전체 작업으로 합쳐 세면 글자 수에 비례하므로 시간은 O(N)입니다.

### 💾 공간 복잡도

짝이 없으면 N개 글자를 저장합니다. 반환값을 포함한 추가 공간은 O(N)입니다.

## ⚠️ 실수하기 쉬운 점

- 스택이 비었을 때 마지막 값을 읽지 않습니다.
- 문자열을 매번 잘라 지우면 같은 부분을 여러 번 복사하게 됩니다.

## ✅ 배운 것

지금까지 남은 글자를 스택에 두면 새 글자와 마지막 글자만 비교해도 됩니다.
