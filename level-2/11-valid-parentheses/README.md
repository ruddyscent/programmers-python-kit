# 🧩 올바른 괄호

- Programmers ID: 12909
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12909
- Level: 2
- Stage: Level 2 Core 11
- Prerequisites: 문자열 순회, 조건문
- Core concepts: 닫히지 않은 괄호 수, 접두 구간 조건

## 🎯 이 문제에서 배우는 것

전체 개수뿐 아니라 읽는 도중에도 규칙이 지켜지는지 확인합니다.

## 🔎 문제 핵심

소괄호로 된 s가 올바르게 열리고 닫히면 True를, 그렇지 않으면 False를 돌려줍니다.

## 💭 먼저 생각해 보기

"())("에는 여는 괄호와 닫는 괄호가 같은 개수입니다. 왼쪽부터 읽으면 어디에서 문제가 생기나요?

## 🧪 예제 이해하기

"(()())"는 끝까지 읽을 때 미완성 괄호 수가 1, 2, 1, 2, 1, 0입니다. 도중에 음수가 없고 끝에 0이라 True입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

여는 괄호면 수를 늘리고 닫는 괄호면 줄입니다. 음수가 되면 짝 없는 닫는 괄호라 바로 실패합니다. 끝에는 수가 0이어야 합니다.

### 🐍 Python 코드

```python
def solution(s):
    unclosed = 0
    for character in s:
        if character == "(":
            unclosed += 1
        else:
            unclosed -= 1
        if unclosed < 0:
            return False
    return unclosed == 0
```

### 📖 코드 해설

여는 괄호를 쌓아 두었다가 닫는 괄호에서 하나씩 꺼낸다고 생각할 수 있습니다. 모두 같은 종류의 소괄호라 실제 목록 대신 개수만 기억해도 됩니다. 서로 다른 종류가 섞인 경우에는 마지막으로 연 종류도 기록해야 합니다.

### ⏱️ 시간 복잡도

길이 N의 각 글자를 한 번 확인하므로 O(N)입니다.

### 💾 공간 복잡도

현재 개수만 저장하므로 반환값을 포함한 추가 공간은 O(1)입니다.

## ⚠️ 실수하기 쉬운 점

- 끝의 개수가 0이라는 조건만으로는 순서를 확인할 수 없습니다.
- 도중에 음수가 나온 뒤 다시 0이 되어도 실패입니다.

## ✅ 배운 것

마지막 조건만 맞는지 확인하는 일과 읽는 도중에도 조건을 지키는 일은 다릅니다.
