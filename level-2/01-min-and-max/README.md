# 🧩 최댓값과 최솟값

- Programmers ID: 12939
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12939
- Level: 2
- Stage: Level 2 Core 01
- Prerequisites: Level 1 평균 구하기, 문자열과 정수 변환
- Core concepts: split(), 값의 크기와 글자의 순서

## 🎯 이 문제에서 배우는 것

문자열을 계산할 수 있는 수로 바꾼 뒤 필요한 결과 형식으로 돌려줍니다.

## 🔎 문제 핵심

공백으로 구분된 정수 문자열 s에서 가장 작은 값과 가장 큰 값을 찾아 두 값을 공백 하나로 연결한 문자열을 돌려줍니다.

## 💭 먼저 생각해 보기

"8 -3 12"의 글자 순서와 숫자 크기 순서는 같을까요? 숫자별로 나누어 적고 최솟값과 최댓값을 고르세요.

## 🧪 예제 이해하기

"8 -3 12"에서는 -3이 가장 작고 12가 가장 큽니다. 결과는 "-3 12"입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

split()으로 공백마다 나눕니다. 각 조각을 int()로 바꿔 리스트에 담고 min(), max()를 적용합니다.

### 🐍 Python 코드

```python
def solution(s):
    numbers = []
    for token in s.split():
        numbers.append(int(token))
    return str(min(numbers)) + " " + str(max(numbers))
```

### 📖 코드 해설

s.split()은 공백을 기준으로 나눈 문자열 리스트를 만듭니다. "12"를 그대로 비교하면 숫자 크기가 아닌 문자 순서를 비교하므로 먼저 int()로 바꿉니다. 반환할 때는 str()로 바꾸어 문자열을 연결합니다.

### ⏱️ 시간 복잡도

입력 문자열 길이를 M, 수의 개수를 N이라 하면 나누고 변환하는 데 O(M), 최솟값과 최댓값을 찾는 데 O(N)이 듭니다. 문제 범위의 정수 변환을 포함해 전체 O(M + N)입니다.

### 💾 공간 복잡도

나뉜 조각과 숫자 리스트를 만듭니다. 반환 문자열까지 포함한 추가 공간은 O(M + N)입니다.

## ⚠️ 실수하기 쉬운 점

- 문자열 상태로 min()을 적용하면 "12"가 "8"보다 앞에 올 수 있습니다.
- 결과 순서는 최솟값, 최댓값이며 사이에 공백 하나가 필요합니다.

## ✅ 배운 것

문자열의 글자 순서와 정수의 크기 순서는 다릅니다. 계산 전에 필요한 자료형으로 바꿉니다.
