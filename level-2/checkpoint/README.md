# 🏁 Level 2 Checkpoint

[Core 30문제](../README.md)를 공부한 뒤 혼자 해결하는 독립 연습입니다. 아래 10문제에는 답 코드·풀이 설명·알고리즘 힌트를 제공하지 않습니다.

## 🧭 연습 규칙

1. 공식 문제를 읽고 입력과 출력, 조건을 자기 말로 적습니다.
2. 작은 예를 손으로 계산하고 해결 방법을 말로 설명합니다.
3. 이전 풀이를 열거나 풀이를 검색하지 않고 코드를 작성합니다. Python 문법은 찾아봐도 됩니다.
4. 프로그래머스에서 채점하고 직접 작성한 코드를 각 폴더의 solution.py에 저장합니다.
5. 도움받은 내용과 채점 결과를 기록하고 1주일 뒤 다시 풉니다. 도움받은 시도는 독립 통과로 세지 않습니다.
