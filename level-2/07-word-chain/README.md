# 🧩 영어 끝말잇기

- Programmers ID: 12981
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12981
- Level: 2
- Stage: Level 2 Core 07
- Prerequisites: 집합 set, 문자열 인덱스, //와 %
- Core concepts: 기록으로 중복 검사, 사람과 차례 계산

## 🎯 이 문제에서 배우는 것

지금까지 나온 단어를 기억하고 실패한 시점의 위치를 계산합니다.

## 🔎 문제 핵심

n명이 순서대로 말한 words에서 처음 규칙을 어긴 사람 번호와 그 사람의 차례를 돌려줍니다. 앞 단어의 끝 글자로 시작해야 하고 이미 나온 단어는 다시 쓸 수 없습니다. 탈락자가 없으면 [0, 0]입니다.

## 💭 먼저 생각해 보기

두 사람이 "cat", "tree", "egg", "go", "cat"을 말했다고 적어 보세요. 다섯 번째 단어는 누가 몇 번째로 말했나요?

## 🧪 예제 이해하기

다섯 번째 "cat"은 끝말도 맞지 않고 이미 나온 단어입니다. 인덱스 4는 1번 사람의 세 번째 차례라 결과는 [1, 3]입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

말한 단어를 seen에 넣습니다. 새 단어를 넣기 전에 중복과 끝말 조건을 확인하고 실패한 첫 위치에서 반환합니다.

### 🐍 Python 코드

```python
def solution(n, words):
    seen = set()
    for index in range(len(words)):
        word = words[index]
        if word in seen:
            return [index % n + 1, index // n + 1]
        if index > 0 and words[index - 1][-1] != word[0]:
            return [index % n + 1, index // n + 1]
        seen.add(word)
    return [0, 0]
```

### 📖 코드 해설

집합은 같은 값의 존재를 빠르게 확인하는 자료형입니다. Python 집합은 해시값이라는 위치 단서를 이용해 값을 찾습니다. index % n은 한 바퀴 안의 위치, index // n은 끝낸 바퀴 수입니다. 둘 다 0부터 세므로 1을 더합니다. 첫 단어에는 이전 단어가 없습니다.

### ⏱️ 시간 복잡도

단어 수를 N, 최대 단어 길이를 L이라 하면 문자열의 해시 계산을 포함해 평균 O(NL)입니다. 집합 조회는 해시 계산 이후 평균 O(1)로 셉니다.

### 💾 공간 복잡도

집합에는 원래 단어를 가리키는 참조를 최대 N개 저장합니다. 문자열을 복사하지 않으므로 반환 리스트를 포함해 추가 공간은 O(N)입니다.

## ⚠️ 실수하기 쉬운 점

- 사람 번호와 차례는 1부터 시작합니다.
