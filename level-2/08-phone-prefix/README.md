## 🎯 이 문제에서 배우는 것

문자열의 앞부분을 후보로 만들어 집합에서 찾습니다.

## 🔎 문제 핵심

phone_book의 한 번호가 다른 번호의 시작 부분이면 False를, 그런 관계가 없으면 True를 돌려줍니다. 번호는 중복되지 않습니다.

## 💭 먼저 생각해 보기

연습 번호 "42", "4219", "742"를 적어 보세요. 앞에 있는 경우와 중간에 있는 경우를 구별할 수 있나요?

## 🧪 예제 이해하기

["42", "4219", "742"]에서는 "42"가 "4219"의 접두어라 False입니다. ["42", "742"]에서는 접두어가 아니므로 True입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

모든 번호를 집합에 넣습니다. 각 번호의 길이보다 짧은 앞부분들을 만들어 집합에 있는지 검사합니다.

### 🐍 Python 코드

```python
def solution(phone_book):
    registered = set(phone_book)
    for phone in phone_book:
        for end in range(1, len(phone)):
            if phone[:end] in registered:
                return False
    return True
```

### 📖 코드 해설

접두어는 문자열이 시작하는 부분입니다. phone[:end]는 end 전까지의 새 문자열입니다. 전체 길이는 제외해 자기 자신을 답으로 판단하지 않습니다. 빈 문자열도 후보에서 제외합니다. 문자로 처리해야 앞의 0을 보존할 수 있습니다.

### ⏱️ 시간 복잡도

번호 수를 N, 최대 길이를 L이라 하면 길이 1부터 L-1까지 복사하고 해시를 계산하는 비용의 합은 O(L²)입니다. 전체 평균 O(NL²)이며 이 문제에서 L은 최대 20입니다.

### 💾 공간 복잡도

번호 집합의 참조 N개와 현재 접두어 문자열 최대 L글자를 저장합니다. 반환값을 포함해 추가 공간은 O(N + L)입니다.

## ⚠️ 실수하기 쉬운 점

- phone in 다른번호는 중간에 있는 문자열도 찾으므로 접두어 검사와 다릅니다.
- 정수로 바꿔 비교하지 않습니다.

## ✅ 배운 것

접두어의 길이를 바꾸어 후보를 만들 때 문자열 복사 비용도 셉니다.
