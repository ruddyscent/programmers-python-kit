# 🧩 N개의 최소공배수

- Programmers ID: 12953
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12953
- Level: 2
- Stage: Level 2 Core 06
- Prerequisites: Level 1 최대공약수와 최소공배수
- Core concepts: 누적 최소공배수, gcd()

## 🎯 이 문제에서 배우는 것

두 수의 계산을 반복해 여러 수의 공통 조건을 만족시킵니다.

## 🔎 문제 핵심

양의 정수 리스트 arr의 모든 수로 나누어 떨어지는 가장 작은 양의 정수를 돌려줍니다.

## 💭 먼저 생각해 보기

3과 4의 공통 배수 12에 6의 조건을 추가하면 답이 바뀌나요? 5의 조건이라면 어떻게 될까요?

## 🧪 예제 이해하기

arr = [3, 4, 6]의 최소공배수는 12입니다. 첫 두 수의 최소공배수 12와 마지막 6의 최소공배수도 12입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

누적값을 1에서 시작합니다. 현재 누적값과 다음 수의 최소공배수를 새 누적값으로 삼습니다.

### 🐍 Python 코드

```python
from math import gcd


def solution(arr):
    multiple = 1
    for number in arr:
        multiple = multiple // gcd(multiple, number) * number
    return multiple
```

### 📖 코드 해설

math.gcd()는 두 정수의 최대공약수를 구하는 표준 라이브러리 함수입니다. 먼저 최대공약수로 나누고 곱하면 두 수의 최소공배수가 됩니다. 누적값은 지금까지 읽은 모든 수의 최소공배수이므로 마지막에는 전체 조건을 만족합니다.

### ⏱️ 시간 복잡도

원소 수를 N, 중간 누적값을 포함한 수의 최댓값을 V라 하면 유클리드 방식 gcd의 반복은 O(log V)로 묶을 수 있어 전체 O(N log V)입니다. 문제의 정수 크기를 한 번의 산술 연산으로 세는 설명입니다.

### 💾 공간 복잡도

누적값과 현재 수만 저장합니다. 문제 범위의 정수 저장을 한 칸으로 세면 반환값을 포함해 O(1)입니다.

## ⚠️ 실수하기 쉬운 점

- 최대공약수가 아니라 최소공배수를 누적합니다.
- 나눗셈에는 //를 써서 정수를 유지합니다.

## ✅ 배운 것

지금까지의 최소공배수를 다음 수와 다시 계산하면 전체의 최소공배수로 확장할 수 있습니다.
