## 🎯 이 문제에서 배우는 것

후보를 작은 순서로 확인해 가장 작은 답을 찾습니다.

## 🔎 문제 핵심

n보다 크고 이진수에서 1의 개수가 n과 같은 수 중 가장 작은 수를 돌려줍니다.

## 💭 먼저 생각해 보기

5를 이진수 "101"로 적고 6과 7의 1 개수를 비교하세요. 어느 후보를 먼저 고를까요?

## 🧪 예제 이해하기

5는 "101"로 1이 두 개입니다. 6은 "110"으로 역시 두 개라 답은 6입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

n의 1 개수를 한 번 저장합니다. n+1부터 검사하고 같은 개수가 나오는 즉시 반환합니다.

### 🐍 Python 코드

```python
def solution(n):
    required_ones = bin(n).count("1")
    candidate = n + 1
    while bin(candidate).count("1") != required_ones:
        candidate += 1
    return candidate
```

### 📖 코드 해설

bin()의 0b에는 1이 없어서 count("1")에는 영향을 주지 않습니다. 후보를 1씩 늘리므로 답 조건에 처음 맞는 수가 최솟값입니다. 매번 n의 개수를 다시 계산할 필요는 없습니다.

### ⏱️ 시간 복잡도

확인한 후보 수를 T, 가장 큰 후보의 이진수 길이를 B라 하면 변환과 세기가 후보마다 O(B)라 전체 O(TB)입니다. 후보 증가량을 상수라고 가정하지 않습니다.

### 💾 공간 복잡도

이진수 문자열을 한 번에 하나씩 만듭니다. 반환값을 포함한 추가 공간은 O(B)입니다.

## ⚠️ 실수하기 쉬운 점

- n부터 검사하면 원래 입력을 그대로 답으로 고르게 됩니다.
- 십진수에 있는 1의 개수와 구별합니다.

## ✅ 배운 것

후보를 작은 순서로 확인하면 처음 맞는 후보가 가장 작은 답입니다.
