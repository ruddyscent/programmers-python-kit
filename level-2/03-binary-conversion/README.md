# 🧩 이진 변환 반복하기

- Programmers ID: 70129
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/70129
- Level: 2
- Stage: Level 2 Core 03
- Prerequisites: 문자열, while, 인덱싱
- Core concepts: 이진수, 상태와 누적 횟수

## 🎯 이 문제에서 배우는 것

한 번의 변환에서 바뀌는 값과 전체 과정에서 쌓이는 값을 구별합니다.

## 🔎 문제 핵심

0과 1로 된 s에서 0을 지우고 남은 길이를 이진수 문자열로 바꿉니다. s가 "1"이 될 때까지 반복해 변환 횟수와 지운 0의 총개수를 돌려줍니다.

## 💭 먼저 생각해 보기

"1010"에서 0을 지우면 글자는 몇 개 남나요? 그 개수를 2의 자리와 1의 자리로 나타내 보세요.

## 🧪 예제 이해하기

"1010"은 1이 두 개라 "10"으로 바뀝니다. 다음에는 1이 한 개라 "1"이 됩니다. 두 번 바꾸고 0을 총 세 개 지웠으므로 [2, 3]입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1의 개수를 세면 실제로 0을 지운 문자열을 만들 필요가 없습니다. 전체 길이에서 1의 개수를 빼 지운 0의 수를 누적하고 1의 개수를 bin()으로 바꿉니다.

### 🐍 Python 코드

```python
def solution(s):
    conversions = 0
    removed_zeros = 0
    while s != "1":
        ones = s.count("1")
        removed_zeros += len(s) - ones
        s = bin(ones)[2:]
        conversions += 1
    return [conversions, removed_zeros]
```

### 📖 코드 해설

s.count("1")은 문자열에서 1이 나온 개수를 셉니다. 이진수는 각 자리에 1, 2, 4, 8처럼 두 배씩 커지는 값을 씁니다. bin(2)는 "0b10"입니다. 앞의 0b는 이진수 표시라 [2:]로 제외합니다. 새 s의 길이는 보통 줄어들지만 "11"을 "10"으로 바꾸면 길이가 2로 같습니다. 이 경우에도 다음 변환에서 "1"이 됩니다. 처음부터 "1"이면 한 번도 변환하지 않습니다.

### ⏱️ 시간 복잡도

처음 문자열의 길이를 N, 각 단계의 길이를 L1, L2, …라고 하면 전체 시간은 O(L1 + L2 + …)입니다. 길이가 6 이상이면 다음 길이는 절반 이하로 줄어듭니다. 길이가 5 이하가 된 뒤에는 많아야 세 번 더 변환하므로 전체 시간은 O(N)입니다.

### 💾 공간 복잡도

한 번에 현재 문자열과 다음 문자열을 저장합니다. 길이 N인 입력에서 반환 리스트를 포함한 추가 공간은 O(N)입니다.

## ⚠️ 실수하기 쉬운 점

- 남은 1의 문자열을 그대로 돌려쓰는 것이 아니라 그 길이를 이진수로 바꿉니다.
- 각 단계에서 지운 0을 누적해야 합니다.

## ✅ 배운 것

현재 문자열은 바뀌어도 전체 변환 횟수와 지운 글자 수는 따로 누적합니다.
