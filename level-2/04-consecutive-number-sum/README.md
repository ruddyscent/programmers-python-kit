# 🧩 숫자의 표현

- Programmers ID: 12924
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12924
- Level: 2
- Stage: Level 2 Core 04
- Prerequisites: while, 누적합, 양의 정수
- Core concepts: 두 포인터, 연속 구간

## 🎯 이 문제에서 배우는 것

연속 구간의 양 끝을 움직여 합계를 갱신합니다.

## 🔎 문제 핵심

자연수 n을 연속된 양의 정수의 합으로 나타내는 방법 수를 돌려줍니다. n 하나만 쓰는 방법도 포함합니다.

## 💭 먼저 생각해 보기

합이 너무 작으면 구간 오른쪽에 수를 붙이고 너무 크면 왼쪽 수를 빼면 어떻게 달라질까요? 수가 모두 양수인 점을 생각하세요.

## 🧪 예제 이해하기

n = 9는 2+3+4, 4+5, 9의 세 방법으로 나타냅니다. 0부터 시작하는 표현은 세지 않습니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

left와 right를 구간의 양 끝으로 둡니다. 오른쪽 수를 더하고 합이 n보다 커지면 왼쪽 수를 뺍니다. 합이 n이면 방법 수를 늘립니다.

### 🐍 Python 코드

```python
def solution(n):
    left = 1
    total = 0
    count = 0
    for right in range(1, n + 1):
        total += right
        while total > n:
            total -= left
            left += 1
        if total == n:
            count += 1
    return count
```

### 📖 코드 해설

구간의 시작과 끝을 가리키는 두 변수를 두 포인터라고 부릅니다. 수를 붙이면 합은 커지고 빼면 작아집니다. 이전 시작점에서 이미 합이 너무 컸다면 오른쪽에 수를 더 붙여도 답이 될 수 없습니다. 그래서 그 시작점으로 돌아갈 필요가 없습니다. 각 끝점에서 가능한 시작점을 빠뜨리지 않습니다.

### ⏱️ 시간 복잡도

right는 n번 움직이고 left도 전체 과정에서 최대 n번 움직입니다. while이 안에 있어도 매번 처음부터 되돌리지 않으므로 전체 O(n)입니다.

### 💾 공간 복잡도

구간의 값들을 별도 리스트에 모으지 않습니다. 반환값을 포함한 추가 공간은 O(1)입니다.

## ⚠️ 실수하기 쉬운 점

- left를 반복마다 1로 되돌리면 같은 구간을 다시 계산하게 됩니다.
- 음수가 섞인 일반 리스트에는 합이 커지고 작아지는 이 논리를 그대로 쓸 수 없습니다.

## ✅ 배운 것

두 포인터가 뒤로 돌아가지 않으면 안쪽 반복문이 있어도 전체 이동 횟수는 작을 수 있습니다.
