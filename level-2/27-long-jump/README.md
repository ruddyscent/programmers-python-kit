# 🧩 멀리 뛰기

- Programmers ID: 12914
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12914
- Level: 2
- Stage: Level 2 Core 27
- Prerequisites: 반복문, 누적값, 나머지
- Core concepts: 동적 계획법, 이전 결과 재사용

## 🎯 이 문제에서 배우는 것

같은 작은 문제를 되풀이해서 풀지 않고 이전 답으로 다음 답을 구합니다.

## 🔎 문제 핵심

한 번에 1칸 또는 2칸씩 이동해 n칸을 가는 방법 수를 1234567로 나눈 나머지를 돌려줍니다.

## 💭 먼저 생각해 보기

5칸에 마지막으로 도착할 때 1칸 뛰었다면 어디에서 출발했나요? 2칸 뛰었다면 어디였나요?

## 🧪 예제 이해하기

5칸의 방법은 4칸까지 가는 5가지에 마지막 1칸을 붙인 경우와, 3칸까지 가는 3가지에 마지막 2칸을 붙인 경우로 나뉘어 총 8가지입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

0칸의 방법은 아무것도 안 하는 한 가지, 1칸의 방법도 한 가지로 둡니다. 새 방법 수는 앞 두 답의 합이므로 두 값만 유지합니다.

### 🐍 Python 코드

```python
def solution(n):
    two_before = 1
    one_before = 1
    for distance in range(2, n + 1):
        current = (two_before + one_before) % 1234567
        two_before = one_before
        one_before = current
    return one_before
```

### 📖 코드 해설

작은 문제의 답을 저장해 다음 답에 쓰는 방법을 동적 계획법(DP)이라고 부릅니다. 마지막 이동이 1칸인 경우와 2칸인 경우는 겹치지 않으므로 더합니다. 나머지를 매번 구해도 최종 합의 나머지는 같습니다. 최신 두 값만 다음 계산에 필요해서 전체 답 목록은 만들지 않습니다.

### ⏱️ 시간 복잡도

거리 n까지 한 번씩 계산하므로 시간은 O(n)입니다.

### 💾 공간 복잡도

이전 두 답과 현재 답만 유지해 반환값 포함 추가 공간은 O(1)입니다.

## ⚠️ 실수하기 쉬운 점

- 0칸의 방법을 0으로 두면 2칸 뛰는 한 방법을 놓칩니다.
- two_before를 먼저 갱신한 값으로 current를 계산하지 않습니다.

## ✅ 배운 것
