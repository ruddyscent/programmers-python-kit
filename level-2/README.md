# 🐍 Skill Check Level 2 Core

[Level 1](../level-1/README.md)의 기본 문법과 풀이 습관을 바탕으로 알고리즘을 배우는 단계입니다. Core 30문제에서 풀이를 이해한 뒤 [Checkpoint 10문제](checkpoint/README.md)를 혼자 해결해 봅니다. 기존 구상의 Level 2 40문제를 이 두 단계로 나누었습니다.

## 🧭 시작하기 전에

Level 1의 다섯 Checkpoint를 도움 없이 풀고 리스트·문자열·조건문·반복문·함수·집합·정렬을 사용할 수 있는지 확인하세요. 아직 막히는 문법은 [Prep](../prep/README.md)과 [Level 1](../level-1/README.md)에서 복습합니다. 합격 여부는 실제 Skill Check 결과로 확인하며 아래 자료 개수는 학습 완료나 합격 기록이 아닙니다.

## 🧭 학습 방법

1. 공식 문제를 읽고 입력과 결과를 자기 말로 설명합니다.
2. 작은 예를 손으로 풀고 변하는 값을 표나 그림으로 기록합니다.
3. 해설과 solution.py를 보기 전에 먼저 접근 방법을 말하고 코드를 작성합니다.
4. 막힌 부분을 확인한 뒤 왜 이 자료구조와 알고리즘을 썼는지 설명합니다.
5. 직접 채점을 통과하고 1주일 뒤 힌트 없이 다시 풉니다. 정답을 외우는 대신 새로운 작은 예에도 같은 생각이 통하는지 확인하세요.

처음 보는 딕셔너리·deque·힙·순열·재귀·DFS/BFS·DP는 사용하는 첫 자료에서 설명합니다. 제출용 solution.py는 README의 첫 풀이와 같습니다. 끝의 추가 연습은 같은 개념을 다시 쓰고 싶을 때 선택합니다. Checkpoint 문제는 독립 연습을 위해 Core의 추가 연습 목록에 넣지 않았습니다.

## ⏱️ 입력 크기와 알고리즘

[Level 1의 복잡도 안내](../level-1/README.md)를 먼저 읽고 입력이 가장 클 때도 반복 횟수가 감당할 만한지 살펴보세요. 8개 던전의 순서를 모두 보는 일과 100,000개 시점을 모두 짝지어 보는 일은 계산량이 다릅니다.

| 표기 | 계산이 늘어나는 모양 | 이 단계에서 확인할 예 |
|---|---|---|
| O(N) | 원소 수에 비례 | 스택에 각 항목을 한 번 넣고 빼기 |
| O(N log N) | 정렬과 힙에서 자주 등장 | 정렬된 사람들의 짝 고르기 |
| O(N²) | 두 위치를 모두 살피기 | 원형 수열의 시작점과 길이 |
| O(2^N) | 매번 두 선택으로 갈라지기 | 각 수의 부호 선택 |
| O(N × N!) | 모든 순서마다 N개 확인 | 최대 8개 던전의 순서 |

N!은 1부터 N까지 곱한 값입니다. 알고리즘 이름만으로 시간을 정하지 말고 실제 코드의 반복·복사·문자열 비교까지 셉니다. 모든 시간 설명의 입력 크기 문자를 먼저 읽으세요. 집합·딕셔너리의 해시 연산은 평균 비용으로 설명하며 긴 문자열의 해시 계산도 셉니다. 수의 산술 연산은 문제에서 허용한 크기에서 한 번으로 세고 추가 공간은 입력 자체를 제외하되 반환값을 포함합니다.

## ✅ 학습 완료 확인

Core 30문제의 해설과 풀이가 준비되어 있습니다. 확인된 학습 완료는 0문제이며 자료 작성과 로컬 검사는 프로그래머스 채점 통과를 뜻하지 않습니다.

개인 학습용 복사본에서 각 문제의 체크리스트를 기록합니다. 채점 통과·1주일 뒤 힌트 없는 재풀이·풀이 설명을 마쳤다면 완료로 세고 이 페이지와 [전체 진도표](../README.md)의 Core·합계 숫자를 함께 수정하세요. 숫자는 자동 집계되지 않습니다. 도움받아 해결한 경우에는 참고한 내용도 기록하고 이후 혼자 다시 풀어 봅니다.

- [ ] 집합의 존재 기록과 딕셔너리의 개수 기록 구별하기
- [ ] 스택·큐·힙의 꺼내는 순서를 작은 예로 설명하기
- [ ] 모든 후보를 볼 수 있는 크기인지 입력 제한으로 판단하기
- [ ] 재귀의 종료 조건과 호출 경로 설명하기
- [ ] BFS에서 먼저 도착한 거리가 최솟값인 이유 설명하기
- [ ] 그리디 선택이 답을 잃지 않는 이유 설명하기
- [ ] DP에서 무엇을 상태로 저장하고 다음 답을 어떻게 만드는지 설명하기
- [ ] 슬라이싱·정렬·반환값의 저장 공간까지 세기

## 🏁 Skill Check Level 2 준비 확인

[Checkpoint 10문제](checkpoint/README.md)를 이전 풀이와 알고리즘 힌트 없이 풀어 보세요. 직접 채점을 통과하고 풀이를 설명하며 복습까지 마쳤다면 Level 2 Skill Check에 도전할 준비를 점검할 수 있습니다. 연습에서 막힌 문제는 기록하고 해당 문법과 사고 과정을 복습한 뒤 다시 혼자 풉니다.
