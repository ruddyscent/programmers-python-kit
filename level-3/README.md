# 🐍 Skill Check Level 3 Core

[Level 2](../level-2/README.md)에서 배운 해시·스택·큐·힙·정렬·완전탐색·DFS/BFS·DP를 더 큰 입력과 복잡한 조건에 적용하는 단계입니다. Core 30문제에서 풀이를 이해한 뒤 [Checkpoint 10문제](checkpoint/README.md)를 혼자 해결해 봅니다.

## 🧭 시작하기 전에

Level 2의 열 Checkpoint를 도움 없이 풀고 딕셔너리·집합·deque·heapq·재귀·BFS를 직접 쓸 수 있는지 확인하세요. 아직 막히는 개념은 [Level 2](../level-2/README.md)에서 먼저 복습합니다. 합격 여부는 실제 Skill Check 결과로 확인하며 아래 자료 개수는 학습 완료나 합격 기록이 아닙니다.

## 🧭 학습 방법

1. 공식 문제를 읽고 입력과 결과를 자기 말로 설명합니다.
2. 입력 제한을 보고 모든 경우를 확인해도 되는지 먼저 판단합니다.
3. 작은 예를 손으로 풀고 변하는 값을 표나 그림으로 기록합니다.
4. 해설과 solution.py를 보기 전에 접근 방법을 말하고 코드를 작성합니다.
5. 막힌 부분을 확인한 뒤 왜 이 자료구조와 알고리즘을 썼는지 설명합니다.
6. 직접 채점을 통과하고 1주일 뒤 힌트 없이 다시 풉니다.

Level 3에서는 쉬운 방법이 너무 느린 경우가 많습니다. 각 해설의 "실수하기 쉬운 점"에서 느린 방법이 왜 시간 안에 끝나지 않는지도 함께 읽으세요. 유니온 파인드·이분 탐색·두 포인터·다익스트라·플로이드 와샬·차이 배열·연결 리스트처럼 처음 나오는 개념은 사용하는 첫 자료에서 설명합니다. 제출용 solution.py는 README의 풀이와 같습니다. Checkpoint 문제는 독립 연습을 위해 Core의 추가 연습 목록에 넣지 않았습니다.

## ⏱️ 입력 크기와 알고리즘

Level 3 문제는 입력이 수십만 개이거나 답의 범위가 수십억에 이르기도 합니다. Python은 1초에 대략 천만 번 안팎의 단순 연산을 처리한다고 어림합니다. 아래 표로 입력 크기에 맞는 방법을 먼저 골라 보세요. 정확한 시간 제한은 문제마다 다르므로 대략적인 기준으로만 씁니다.

| 표기 | 계산이 늘어나는 모양 | 이 단계에서 확인할 예 |
|---|---|---|
| O(log H) | 답의 범위를 반씩 줄이기 | 입국심사의 시간 범위 |
| O(N) | 원소마다 한두 번 | 보석 쇼핑의 두 포인터 |
| O(N log N) | 정렬과 힙 | 디스크 컨트롤러의 작업 선택 |
| O(N + E) | 점과 연결선을 한 번씩 | 가장 먼 노드의 BFS |
| O(N²) | 두 대상을 모두 짝짓기 | 네트워크의 인접 행렬 |
| O(N³) | 세 대상을 모두 조합 | 순위의 플로이드 와샬 |

E는 그래프의 간선 수, H는 이분 탐색할 답의 범위 크기입니다. 모든 시간 설명의 입력 크기 문자는 각 README에서 먼저 정의합니다. 집합·딕셔너리의 해시 연산은 평균 비용으로 설명하며 수의 산술 연산은 문제에서 허용한 크기에서 한 번으로 셉니다. 추가 공간은 입력 자체를 제외하고 반환값을 포함합니다.
