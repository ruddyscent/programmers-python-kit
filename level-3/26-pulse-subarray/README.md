# 🧩 연속 펄스 부분 수열의 합

- Programmers ID: 161988
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/161988
- Level: 3
- Stage: Level 3 Core 26
- Prerequisites: 25 직전 값만 기억하는 DP, max()
- Core concepts: 연속 부분합의 최댓값, 카데인 알고리즘

## 🎯 이 문제에서 배우는 것

"여기서 끝나는 가장 큰 연속합"만 기억해 최대 연속합을 한 번에 구합니다.

## 🔎 문제 핵심

sequence의 연속 부분 수열을 고르고 같은 길이의 펄스 수열을 원소별로 곱합니다. 펄스 수열은 1과 -1이 번갈아 나오며 1로 시작할 수도 -1로 시작할 수도 있습니다. 곱한 결과의 합 중 가장 큰 값을 돌려줍니다.

## 💭 먼저 생각해 보기

펄스를 먼저 곱해 새 수열을 만들면 문제는 무엇으로 바뀌나요? 지금까지 이어 온 합이 음수라면 그 합을 계속 끌고 가는 것이 좋을까요?

## 🧪 예제 이해하기

sequence = [3, -1, 2]입니다. [1, -1, 1]을 곱하면 [3, 1, 2]이고 전체 합 6이 가장 큽니다. [-1, 1, -1]을 곱하면 [-3, -1, -2]이고 가장 큰 연속합은 -1입니다. 결과는 6입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

펄스 두 가지를 각각 곱한 수열에서 연속합의 최댓값을 구합니다. 각 위치에서 끝나는 가장 큰 합은 "현재 값만" 또는 "직전 위치에서 끝나는 가장 큰 합 + 현재 값" 중 큰 값입니다.

### 🐍 Python 코드

```python
def solution(sequence):
    best = sequence[0]
    for first_sign in [1, -1]:
        sign = first_sign
        ending_here = 0
        for value in sequence:
            pulsed = value * sign
            ending_here = max(pulsed, ending_here + pulsed)
            best = max(best, ending_here)
            sign = -sign
    return best
```

### 📖 코드 해설

sign은 펄스 값이며 매 칸마다 부호를 바꿉니다. ending_here는 현재 칸에서 끝나는 연속 구간 가운데 합이 가장 큰 값입니다. 직전까지의 합이 음수면 현재 값만으로 새로 시작하는 쪽이 커집니다. best는 지금까지 본 ending_here의 최댓값입니다. 처음 값 sequence[0]은 길이 1 구간의 합이라 실제로 가능한 후보입니다.

이처럼 끝나는 위치마다 최대 합을 이어 계산하는 방법을 카데인(Kadane) 알고리즘이라고 합니다.

```text
펄스 곱   3   1   2
ending   3   4   6
best     3   4   6
```

### ⏱️ 시간 복잡도

수열 길이를 N이라 하면 두 번 훑어 O(N)입니다.

### 💾 공간 복잡도

곱한 수열을 따로 만들지 않고 변수 몇 개만 써 O(1)입니다.

## ⚠️ 실수하기 쉬운 점

- 모든 시작과 끝을 확인하면 O(N²)이라 50만 길이에서 느립니다.
- best를 0으로 시작하면 모든 값이 음수일 때 빈 구간을 고른 것처럼 됩니다. 구간은 적어도 한 칸입니다.
- 두 번째 펄스는 -1로 시작한다는 것을 잊지 않습니다.

## ✅ 배운 것

끝나는 위치별 최댓값을 이어 계산하면 모든 구간을 보지 않고 최대 연속합을 구할 수 있습니다.
