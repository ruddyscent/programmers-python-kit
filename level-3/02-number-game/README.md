# 🧩 숫자 게임

- Programmers ID: 12987
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12987
- Level: 3
- Stage: Level 3 Core 02
- Prerequisites: sorted(), Level 2 19 두 위치를 함께 움직이기
- Core concepts: 정렬 후 그리디 짝짓기

## 🎯 이 문제에서 배우는 것

두 리스트를 정렬하고 가장 아깝지 않은 짝을 고르는 그리디 방법을 연습합니다.

## 🔎 문제 핵심

A팀의 출전 순서 A가 정해져 있고 B팀은 B의 숫자를 마음대로 배치합니다. 같은 경기에서 더 큰 수가 이기며 같으면 아무도 이기지 않습니다. B팀이 얻을 수 있는 최대 승점을 돌려줍니다.

## 💭 먼저 생각해 보기

A의 1을 이기는 데 B의 9를 쓰면 아깝습니다. A의 작은 수부터 볼 때 B는 어떤 수를 내야 할까요?

## 🧪 예제 이해하기

A = [4, 2, 7], B = [3, 5, 6]을 정렬하면 A는 [2, 4, 7], B는 [3, 5, 6]입니다. B의 3은 A의 2를, 5는 4를 이깁니다. 6은 7을 이길 수 없습니다. 결과는 2입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

둘 다 오름차순으로 정렬합니다. B의 작은 수부터 보면서 아직 이기지 못한 A 가운데 가장 작은 수를 이길 수 있으면 짝을 짓습니다. 못 이기는 B의 수는 어차피 다른 A도 이길 수 없으므로 버리는 경기에 씁니다.

### 🐍 Python 코드

```python
def solution(A, B):
    team_a = sorted(A)
    team_b = sorted(B)
    wins = 0
    a_index = 0
    for b_number in team_b:
        if b_number > team_a[a_index]:
            wins += 1
            a_index += 1
    return wins
```

### 📖 코드 해설

a_index는 아직 이기지 못한 A 가운데 가장 작은 수의 위치입니다. b_number가 그 수보다 크면 승리를 하나 세고 다음 A로 넘어갑니다. 경기 순서는 문제의 답과 상관없으므로 A를 정렬해도 됩니다. 이긴 횟수만 필요하기 때문입니다. b_number가 이기지 못하면 a_index를 그대로 두고 다음 B를 봅니다.

```text
A: 2 4 7     B: 3 5 6
   ^            ^       3 > 2 승리
     ^            ^     5 > 4 승리
       ^            ^   6 < 7 패배
```

a_index는 B를 하나 볼 때 최대 한 번 늘어나므로 B를 모두 보기 전에 리스트 범위를 넘지 않습니다.

### ⏱️ 시간 복잡도

각 팀의 인원을 N이라 하면 두 번의 정렬이 O(N log N), 짝짓기가 O(N)이라 전체 O(N log N)입니다.

### 💾 공간 복잡도

정렬한 두 리스트를 새로 만들어 O(N)을 사용합니다. 반환값은 정수 하나입니다.

## ⚠️ 실수하기 쉬운 점

- 같은 수는 이긴 것이 아닙니다. >= 대신 >를 씁니다.
- B의 큰 수부터 무조건 쓰면 작은 A를 이길 기회를 낭비할 수 있습니다.

## ✅ 배운 것

이길 수 있는 가장 작은 수로 이기면 큰 수를 다음 경기에 아껴 둘 수 있습니다.
