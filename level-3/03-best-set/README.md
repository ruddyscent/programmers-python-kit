# 🧩 최고의 집합

- Programmers ID: 12938
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12938
- Level: 3
- Stage: Level 3 Core 03
- Prerequisites: 몫 //, 나머지 %, 리스트 반복 *
- Core concepts: 고르게 나누기, 수학적 관찰

## 🎯 이 문제에서 배우는 것

모든 경우를 만들어 보지 않고 규칙을 찾아 바로 답을 만듭니다.

## 🔎 문제 핵심

자연수 n개의 합이 s일 때 곱이 가장 큰 묶음을 오름차순 리스트로 돌려줍니다. 그런 묶음이 없으면 [-1]입니다.

## 💭 먼저 생각해 보기

합이 10인 두 자연수 가운데 곱이 가장 큰 것은 무엇인가요? 1과 9, 3과 7, 5와 5를 비교해 보세요.

## 🧪 예제 이해하기

n = 3, s = 11이면 11을 3으로 나눈 몫은 3, 나머지는 2입니다. 세 수를 3으로 두고 두 수에 1씩 더해 [3, 4, 4]를 만듭니다. 곱은 48입니다. n = 4, s = 3이면 자연수 네 개의 합은 적어도 4이므로 [-1]입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

두 수의 차이가 2 이상이면 큰 수에서 1을 빼 작은 수에 주어도 합은 같고 곱은 커집니다. 그래서 모든 수의 차이가 1 이하일 때 곱이 가장 큽니다. 몫을 기본값으로 두고 나머지만큼 1을 더 줍니다.

### 🐍 Python 코드

```python
def solution(n, s):
    if n > s:
        return [-1]
    base = s // n
    extra = s % n
    return [base] * (n - extra) + [base + 1] * extra
```

### 📖 코드 해설

[base] * (n - extra)는 base를 n - extra번 담은 리스트를 만듭니다. 두 리스트를 +로 이으면 작은 수가 앞에 와서 정렬하지 않아도 오름차순입니다. n이 s보다 크면 1만 써도 합이 넘쳐 묶음이 없습니다.

곱이 커지는 이유는 a와 b(a + 2 ≤ b)를 a + 1과 b - 1로 바꿔 보면 알 수 있습니다. (a + 1) × (b - 1) - a × b = b - a - 1이고 이 값은 1 이상입니다.

### ⏱️ 시간 복잡도

리스트에 n개의 수를 담으므로 O(n)입니다. 나눗셈은 한 번씩만 합니다.

### 💾 공간 복잡도

반환 리스트가 n칸이므로 O(n)입니다.

## ⚠️ 실수하기 쉬운 점

- 1을 더 받는 수를 뒤쪽에 두어야 오름차순입니다.
- 실패할 때 -1 하나가 아니라 [-1] 리스트를 돌려줍니다.
