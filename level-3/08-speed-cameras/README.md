# 🧩 단속카메라

- Programmers ID: 42884
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/42884
- Level: 3
- Stage: Level 3 Core 08
- Prerequisites: 01 정렬 기준 함수, None
- Core concepts: 구간, 끝점 기준 그리디

## 🎯 이 문제에서 배우는 것

구간을 끝나는 위치 순서로 보고 가장 늦게까지 버티는 위치를 고르는 그리디 방법을 배웁니다.

## 🔎 문제 핵심

routes[i]는 차량이 고속도로에 들어온 지점과 나간 지점입니다. 모든 차량이 적어도 한 번 카메라를 지나도록 할 때 필요한 카메라의 최소 개수를 돌려줍니다. 들어온 지점이나 나간 지점에 있는 카메라도 지난 것으로 봅니다.

## 💭 먼저 생각해 보기

가장 먼저 고속도로를 나가는 차를 생각해 봅시다. 그 차를 찍으려면 카메라를 그 차의 구간 안에 둬야 합니다. 그 안에서 어느 위치가 다른 차도 가장 많이 찍을 수 있을까요?

## 🧪 예제 이해하기

routes = [[1, 4], [2, 6], [5, 8], [7, 9]]를 나가는 지점 순서로 보면 [1, 4]가 먼저입니다. 4에 카메라를 두면 [2, 6]도 찍힙니다. [5, 8]은 5가 4보다 커서 새 카메라를 8에 둡니다. [7, 9]는 8에서 찍힙니다. 결과는 2입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

나가는 지점이 빠른 차부터 봅니다. 마지막 카메라가 이 차의 구간 안에 없으면 이 차가 나가는 지점에 새 카메라를 둡니다.

### 🐍 Python 코드

```python
def solution(routes):
    def exit_point(route):
        return route[1]

    cameras = 0
    camera_position = None
    for start, end in sorted(routes, key=exit_point):
        if camera_position is None or start > camera_position:
            cameras += 1
            camera_position = end
    return cameras
```

### 📖 코드 해설

exit_point는 정렬 기준으로 나가는 지점을 돌려줍니다. camera_position은 마지막으로 설치한 카메라 위치이며 처음에는 아무 위치도 없다는 뜻의 None입니다. 차량을 끝점 순서로 보므로 이 차의 끝점은 마지막 카메라 위치보다 앞에 있지 않습니다. 그래서 들어온 지점이 카메라 위치보다 뒤에 있는지만 확인하면 됩니다.

나가는 지점에 두는 선택이 안전한 이유가 있습니다. 이 차를 찍는 카메라는 반드시 이 차의 구간 안에 있어야 합니다. 그중 가장 오른쪽인 끝점은 아직 나가지 않은 다른 차를 찍을 기회가 가장 많습니다.

```text
1---4                카메라 4
  2----6             4에서 찍힘
       5---8         카메라 8
         7--9        8에서 찍힘
```

### ⏱️ 시간 복잡도

차량 수를 N이라 하면 정렬에 O(N log N), 한 번 훑는 데 O(N)이라 전체 O(N log N)입니다.

### 💾 공간 복잡도

sorted()가 만든 새 리스트에 O(N)을 사용합니다.

## ⚠️ 실수하기 쉬운 점

- 들어온 지점 순서로 정렬하면 긴 구간 하나 때문에 카메라 위치를 잘못 정하기 쉽습니다.
- 들어온 지점이 카메라 위치와 같으면 이미 찍힌 것입니다. >를 써서 새 카메라를 만들지 않습니다.

## ✅ 배운 것

가장 먼저 끝나는 구간을 기준으로 끝점에 설치하면 다른 구간까지 최대한 함께 처리할 수 있습니다.
