# 🧩 입국심사

- Programmers ID: 43238
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/43238
- Level: 3
- Stage: Level 3 Core 11
- Prerequisites: 몫 //, while, min()
- Core concepts: 이분 탐색, 답을 정하고 확인하기

## 🎯 이 문제에서 배우는 것

답의 후보 범위를 반씩 줄이는 이분 탐색을 배웁니다.

## 🔎 문제 핵심

n명이 심사를 기다리고 심사관 i는 한 명을 심사하는 데 times[i]분이 걸립니다. 한 심사관은 한 번에 한 명만 심사하고 빈 심사관에게 누구든 갈 수 있습니다. 모두 심사를 받는 데 걸리는 최소 시간을 돌려줍니다.

## 💭 먼저 생각해 보기

"10분 안에 모두 끝낼 수 있을까?"라는 질문에는 쉽게 답할 수 있나요? 각 심사관이 10분 동안 몇 명을 심사할 수 있는지 세어 보세요.

## 🧪 예제 이해하기

n = 5, times = [2, 3]입니다. 6분이면 6 // 2 = 3명, 6 // 3 = 2명으로 5명을 끝냅니다. 5분이면 5 // 2 = 2명, 5 // 3 = 1명이라 3명뿐입니다. 결과는 6입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

시간 T가 주어지면 T // times[i]를 모두 더해 T분 동안 심사할 수 있는 사람 수를 셉니다. T가 늘면 이 수도 줄지 않습니다. 가능한 가장 작은 T를 범위를 반씩 줄이며 찾습니다.

### 🐍 Python 코드

```python
def solution(n, times):
    low = 1
    high = min(times) * n
    while low < high:
        middle = (low + high) // 2
        people = 0
        for time in times:
            people += middle // time
        if people >= n:
            high = middle
        else:
            low = middle + 1
    return low
```

### 📖 코드 해설

low와 high 사이에 답이 있다는 약속을 지키며 범위를 줄입니다. 가장 빠른 심사관 혼자 모두 심사하면 min(times) * n분이면 충분하므로 이 값이 high입니다. middle분에 n명 이상 심사할 수 있으면 답은 middle 이하이므로 high = middle입니다. 부족하면 답은 middle보다 크므로 low = middle + 1입니다. low와 high가 같아지면 그 값이 답입니다.

```text
범위 [1, 10]  가운데 5  -> 3명, 부족  -> [6, 10]
범위 [6, 10]  가운데 8  -> 6명, 충분  -> [6, 8]
범위 [6, 8]   가운데 7  -> 5명, 충분  -> [6, 7]
범위 [6, 7]   가운데 6  -> 5명, 충분  -> [6, 6]
```

이처럼 가능한 답을 하나 정하고 조건을 확인하는 방법은 답의 범위가 아주 클 때 특히 유용합니다.

### ⏱️ 시간 복잡도

심사관 수를 M, 처음 범위의 크기를 H = min(times) × n이라 합니다. 범위가 매번 반으로 줄어 O(log H)번 확인하고 확인마다 O(M)이 걸려 전체 O(M log H)입니다.

### 💾 공간 복잡도

변수 몇 개만 사용하므로 O(1)입니다.

## ⚠️ 실수하기 쉬운 점

- 시간을 1분씩 늘려 가며 확인하면 최대 10^18분까지 갈 수 있어 끝나지 않습니다.
- 조건을 만족할 때 high = middle - 1로 줄이면 답을 잃을 수 있습니다.
- Python 정수는 커져도 넘치지 않지만 다른 언어로 옮길 때는 큰 정수형이 필요합니다.
