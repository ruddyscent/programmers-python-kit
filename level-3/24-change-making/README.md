# 🧩 거스름돈

- Programmers ID: 12907
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/12907
- Level: 3
- Stage: Level 3 Core 24
- Prerequisites: 23 경우의 수 DP, 나머지 연산
- Core concepts: 순서를 세지 않는 조합 DP

## 🎯 이 문제에서 배우는 것

동전을 한 종류씩 추가하며 금액별 방법 수를 갱신해 순서가 다른 같은 조합을 한 번만 셉니다.

## 🔎 문제 핵심

거스름돈 n원을 money의 동전들로 줍니다. 각 동전은 개수 제한 없이 쓸 수 있습니다. 동전 개수의 조합이 다르면 다른 방법이며 같은 동전들을 다른 순서로 주는 것은 같은 방법입니다. 방법의 수를 1,000,000,007로 나눈 나머지로 돌려줍니다.

## 💭 먼저 생각해 보기

1원과 2원으로 3원을 만드는 방법은 몇 가지인가요? 1+2와 2+1을 따로 세지 않으려면 어떤 순서로 계산해야 할까요?

## 🧪 예제 이해하기

n = 4, money = [1, 2]입니다. 1원만 쓰면 모든 금액이 한 가지입니다. 2원을 추가하면 2원은 2가지, 3원은 2가지, 4원은 1+1+1+1, 1+1+2, 2+2로 3가지가 됩니다. 결과는 3입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

ways[price]는 지금까지 본 동전으로 price원을 만드는 방법 수입니다. 0원은 아무것도 내지 않는 한 가지입니다. 동전 coin을 추가할 때 ways[price]에 ways[price - coin]을 더합니다. coin을 적어도 하나 쓰는 방법들이 새로 생기기 때문입니다.

### 🐍 Python 코드

```python
def solution(n, money):
    divisor = 1000000007
    ways = [0] * (n + 1)
    ways[0] = 1
    for coin in money:
        for price in range(coin, n + 1):
            ways[price] = (ways[price] + ways[price - coin]) % divisor
    return ways[n]
```

### 📖 코드 해설

바깥 반복이 동전 종류이므로 각 방법은 동전 종류를 money 순서대로 쓰는 모양으로만 셉니다. 그래서 1+2와 2+1이 따로 세어지지 않습니다. 반복 순서를 바꿔 금액을 바깥에 두면 순서가 다른 방법까지 세어 답이 커집니다.

안쪽 반복은 작은 금액부터 갑니다. ways[price - coin]에 이미 이번 동전을 쓴 방법이 들어 있어 같은 동전을 여러 개 쓰는 경우가 자연스럽게 포함됩니다.

```text
금액      0 1 2 3 4
처음      1 0 0 0 0
1원 추가  1 1 1 1 1
2원 추가  1 1 2 2 3
```

### ⏱️ 시간 복잡도

금액을 n, 동전 종류 수를 C라 하면 표를 C번 훑어 O(nC)입니다.

### 💾 공간 복잡도

ways 리스트에 O(n)을 사용합니다.

## ⚠️ 실수하기 쉬운 점

- 금액을 바깥 반복으로 두면 순서가 다른 방법을 따로 셉니다.
- ways[0] = 1을 빼먹으면 모든 값이 0이 됩니다.

## ✅ 배운 것
