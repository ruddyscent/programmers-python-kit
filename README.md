# programmers-python-kit

A structured Python learning kit for Programmers Skill Check and coding tests, from Python basics to algorithm problem solving.

## 학습 목표

Python을 처음 배우는 초등학교 5학년 학생이 기초 문법부터 차근차근 익혀 프로그래머스 Skill Check Level 1에 도전할 수 있도록 돕는 학습 저장소입니다.

정답을 한 번 맞히는 데서 끝내지 않습니다. 풀이 방법을 자기 말로 설명하고 시간이 지난 뒤에도 힌트 없이 다시 풀 수 있는 것을 목표로 합니다.

## 커리큘럼

| 단계 | 문제 수 | 학습자료 | 학습 완료 확인 | 목표 |
|---|---:|---:|---:|---|
| [Python Prep](prep/) | 20 | 20 | 0 | Python 기본 문법 익히기 |
| Skill Check Level 1 Core | 25 | 0 | 0 | Level 1 문제 해결 패턴 익히기 |
| Level 1 Checkpoint | 5 | 0 | 0 | 도움 없이 실전 문제 풀기 |
| **합계** | **50** | **20** | **0** | **Skill Check Level 1 준비** |

`학습자료`는 README와 예제 풀이가 준비된 수입니다. `학습 완료 확인`은 학습자가 직접 문제를 풀었다고 확인된 수입니다. 저장소에 풀이 코드가 있다고 해서 학습을 마친 것으로 기록하지 않습니다.

## 학습 순서

1. 문제 링크를 열고 무엇을 입력받고 무엇을 돌려줘야 하는지 확인합니다.
2. 작은 예를 손으로 계산하고 해결 방법을 말로 설명해 보세요.
3. 먼저 혼자 코드를 작성해 봅니다.
4. 막힐 때는 학습자료의 설명과 풀이를 단계별로 확인하세요.
5. 프로그래머스 채점을 통과한 뒤, 1주일 후 다시 풀어 봅니다.

## 저작권과 라이선스

이 저장소가 직접 작성한 풀이 코드, 해설, 학습 노트, 커리큘럼에는 [MIT License](LICENSE)가 적용됩니다.

프로그래머스의 문제 원문, 제한사항, 공식 입출력 예, 이미지, 테스트케이스의 저작권은 프로그래머스와 각 원저작자에게 있습니다. 이 저장소는 공식 문제 원문을 복제하지 않고 문제 제목, ID, 공식 링크와 직접 작성한 요약·예제·풀이를 기록합니다.
