# 옷가게 할인 받기

- Core concepts: 구간별 조건, 큰 기준부터 검사하기, 몫 연산자 `//`

## 이 문제에서 배우는 것

가격 구간마다 다른 계산을 고르는 방법을 배웁니다. 조건이 겹칠 때는 더 큰 할인 기준부터 확인해야 한다는 점도 익힙니다.

## 문제 핵심

구매 가격이 커질수록 할인율이 달라집니다. 가장 높은 기준을 만족하는 할인 하나만 적용하고 계산 결과의 소수점 아래는 버립니다.

## 먼저 생각해 보기

`price`가 360,000원이라면 어느 기준을 만족하는지 살펴보세요. 100,000원 기준과 300,000원 기준을 모두 만족하지만 실제로 적용할 할인은 더 큰 300,000원 기준의 할인입니다.

## 예제 이해하기

`price`가 320,000원이라고 해 봅시다. 10%를 할인하면 원래 가격의 90%를 냅니다. 따라서 `320000 * 90 // 100`을 계산하면 288,000원이 됩니다.

## 풀이 1. 이해하기 쉬운 방법

### 아이디어

500,000원, 300,000원, 100,000원 순서로 검사합니다. 할인 뒤에 내는 비율은 각각 80%, 90%, 95%입니다. 어떤 기준에도 닿지 않으면 원래 가격을 그대로 반환합니다.

### Python 코드

```python
def solution(price):
    if price >= 500000:
        return price * 80 // 100
    if price >= 300000:
        return price * 90 // 100
    if price >= 100000:
        return price * 95 // 100
    return price
```

### 코드 해설

가장 큰 기준부터 확인하므로 500,000원 이상인 가격에 더 낮은 할인율을 잘못 적용하지 않습니다. `//`는 나눈 몫만 남겨 소수점 아래를 버립니다. 곱셈을 먼저 해서 정수만으로 계산합니다.

### 시간 복잡도

조건을 최대 세 번 확인하므로 시간 복잡도는 `O(1)`입니다.

### 공간 복잡도

새로운 리스트나 큰 저장 공간을 만들지 않습니다. 공간 복잡도는 `O(1)`입니다.

## 실수하기 쉬운 점

- 기준 금액과 같은 가격도 할인을 받으므로 `>`가 아니라 `>=`를 사용합니다.
- 100,000원부터 검사하면 더 큰 가격도 첫 조건에서 함수가 끝날 수 있습니다.
- 20% 할인은 가격의 20%를 내는 것이 아니라 80%를 내는 뜻입니다.

## 배운 것

- 조건이 겹치면 더 구체적이고 큰 기준부터 확인합니다.
- `//`로 나눗셈 결과의 소수점 아래를 버립니다.
- 조건마다 `return`하면 선택한 계산 뒤에 함수가 끝납니다.
