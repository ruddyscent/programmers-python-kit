# 🧩 문자 반복 출력하기

- Programmers ID: 120825
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120825
- Level: 0
- Stage: Python Prep 16
- Prerequisites: 문자열, `for`, 문자열 덧셈과 곱셈
- Core concepts: 문자열 순회, 문자 반복, 결과 이어 붙이기

## 🎯 이 문제에서 배우는 것

문자열도 리스트처럼 앞에서부터 한 글자씩 꺼냅니다. Python에서는 문자열에 정수를 곱해 같은 글자를 여러 번 이어 붙입니다.

## 🔎 문제 핵심

문자열 전체를 여러 번 반복하는 문제가 아닙니다. 각 글자를 `n`번씩 반복한 뒤 차례대로 이어 붙여야 합니다.

## 💭 먼저 생각해 보기

`"Cat"`의 각 글자를 2번씩 쓴다고 생각해 보세요. `C`, `a`, `t`를 각각 반복한 결과를 어떤 순서로 붙여야 하는지 말해 봅니다.

## 🧪 예제 이해하기

`my_string`이 `"Cat"`이고 `n`이 2라면 `C`는 `"CC"`, `a`는 `"aa"`, `t`는 `"tt"`가 됩니다. 이 문자열들을 순서대로 붙인 결과는 `"CCaatt"`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1. 결과를 담을 빈 문자열 `answer`를 만듭니다.
2. `my_string`에서 글자를 하나씩 꺼냅니다.
3. `character * n`으로 그 글자를 `n`번 반복합니다.
4. 반복한 글자를 `answer` 뒤에 붙입니다.

### 🐍 Python 코드

```python
def solution(my_string, n):
    answer = ""

    for character in my_string:
        answer += character * n

    return answer
```

### 📖 코드 해설

`"A" * 3`의 결과는 `"AAA"`입니다. 반복문은 원래 문자열의 글자 순서를 지켜서 실행됩니다. `answer += ...`는 새로 만든 문자열을 지금까지의 결과 뒤에 이어 붙입니다.

### ⏱️ 반복 횟수와 저장 공간

원래 문자열의 길이가 `m`이라면 반복문은 `m`번 돕니다. 완성되는 문자열에는 모두 `m × n`개의 글자가 들어갑니다.

## ⚠️ 실수하기 쉬운 점

- `my_string * n`은 문자열 전체를 반복하므로 원하는 결과와 다릅니다.
- 영어 대문자와 소문자는 서로 다른 글자입니다. 원래 모양을 그대로 반복합니다.
- 완성한 문자열을 `return`해야 합니다.

## ✅ 배운 것

- 문자열을 `for`로 돌면 글자를 앞에서부터 하나씩 꺼냅니다.
- 문자열에 정수를 곱하면 같은 문자열이 그 횟수만큼 반복됩니다.
- 빈 문자열에 조각을 더하며 결과를 만듭니다.
