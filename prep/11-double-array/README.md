# 🧩 배열 두 배 만들기

- Programmers ID: 120809
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120809
- Level: 0
- Stage: Python Prep 11
- Prerequisites: 함수, 리스트, `for`, `append()`, 곱셈, `return`
- Core concepts: 리스트 순회, 값 바꾸기, 새 리스트 만들기

## 🎯 이 문제에서 배우는 것

리스트의 값을 하나씩 꺼내 계산하고 결과를 새 리스트에 모으는 기본 모양을 배웁니다. 원래 리스트를 그대로 두고 새 결과를 만드는 방법도 익힙니다.

## 🔎 문제 핵심

`numbers`에 있는 모든 수에 2를 곱해야 합니다. 수 하나만 반환하는 것이 아니라, 계산한 값들을 처음과 같은 순서로 담은 리스트를 반환해야 합니다.

## 💭 먼저 생각해 보기

종이에 빈 리스트를 그린 뒤 `[4, -1, 0]`의 값을 하나씩 꺼내 보세요. 2를 곱한 8, -2, 0을 차례로 빈 리스트에 넣으면 됩니다.

## 🧪 예제 이해하기

`numbers`가 `[3, 6, -2]`라면 차례로 `3 * 2`, `6 * 2`, `-2 * 2`를 계산합니다. 결과는 `[6, 12, -4]`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

결과를 모을 빈 리스트를 만듭니다. `for`로 모든 수를 방문하면서 2를 곱한 값을 `append()`로 추가합니다.

### 🐍 Python 코드

```python
def solution(numbers):
    doubled_numbers = []

    for number in numbers:
        doubled_numbers.append(number * 2)

    return doubled_numbers
```

### 📖 코드 해설

`for number in numbers`는 리스트의 값을 앞에서부터 하나씩 `number`에 담습니다. `append()`는 새 값을 결과 리스트의 맨 뒤에 붙입니다. 반복이 끝나면 완성된 리스트를 반환합니다.

### ⏱️ 시간 복잡도

`numbers`의 길이를 `n`이라고 하면 모든 원소를 한 번씩 처리합니다. 시간 복잡도는 `O(n)`입니다.

### 💾 공간 복잡도

원소 `n`개가 들어가는 결과 리스트를 새로 만듭니다. 반환할 결과를 포함한 공간 복잡도는 `O(n)`입니다.

## ⚠️ 실수하기 쉬운 점

- `numbers * 2`는 각 숫자를 두 배로 만드는 연산이 아닙니다. 리스트 자체를 두 번 이어 붙입니다.
- 계산 결과를 `append()`하지 않으면 새 리스트는 계속 비어 있습니다.
- 반복이 모두 끝난 뒤에 결과 리스트를 반환해야 합니다.

## ✅ 배운 것

- `for`로 리스트의 모든 값을 차례로 봅니다.
- `append()`로 결과를 하나씩 모읍니다.
- 원본과 결과를 서로 다른 리스트로 관리합니다.
