## 이 문제에서 배우는 것

조건에 따라 다른 값을 돌려주는 `if` 문을 배웁니다. 두 값이 같은지 물을 때는 `==`를 사용합니다.

## 문제 핵심

`num1`과 `num2`가 같으면 1을, 다르면 -1을 반환합니다. 가능한 결과는 두 가지입니다.

## 먼저 생각해 보기

1. 두 수가 같은 경우를 먼저 확인해 보세요.
2. 같을 때 어떤 값을 반환해야 하나요?
3. 같지 않다면 남은 답은 무엇인가요?

## 예제 이해하기

`num1`과 `num2`가 모두 42라면 두 수는 같으므로 결과는 1입니다. 한쪽이 41이라면 결과는 -1입니다.

## 풀이 1. `if`로 같은지 확인하기

### 아이디어

`num1 == num2`가 참이면 바로 1을 반환합니다. 이 조건이 거짓일 때만 마지막 줄로 내려가 -1을 반환합니다.

### Python 코드

```python
def solution(num1, num2):
    if num1 == num2:
        return 1

    return -1
```

### 코드 해설

`if` 뒤의 조건이 참이면 들여쓴 코드가 실행됩니다. `return 1`을 만나면 함수가 끝나므로, 두 수가 다를 때만 마지막의 `return -1`까지 내려갑니다.

### 시간 복잡도

두 수를 한 번 비교하므로 `O(1)`입니다.

### 공간 복잡도

새로운 자료 모음을 만들지 않으므로 `O(1)`입니다.

## 실수하기 쉬운 점

- `=`는 값을 저장할 때 쓰고 `==`는 두 값이 같은지 비교할 때 씁니다.
- `if` 줄 끝의 콜론 `:`과 다음 줄의 들여쓰기를 빠뜨리지 마세요.
- 같을 때와 다를 때 돌려줄 숫자를 서로 바꾸지 마세요.

## 배운 것

- `if`는 조건이 참일 때만 안쪽 코드를 실행합니다.
- `==`는 두 값이 같은지 확인합니다.
- `return`이 실행되면 함수는 바로 끝납니다.
