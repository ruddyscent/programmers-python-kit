# 🧩 나이 출력

- Programmers ID: 120820
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120820
- Level: 0
- Stage: Python Prep 10
- Prerequisites: 함수, 변수, 뺄셈, `return`
- Core concepts: 식 세우기, 한국식 나이와 출생 연도의 관계

## 🎯 이 문제에서 배우는 것

나이 계산은 글로 설명되어 있습니다. 이 설명을 하나의 뺄셈 식으로 바꾸는 연습을 합니다. 문제에서 정한 기준 연도와 나이 세는 방법을 정확히 읽는 것도 중요합니다.

## 🔎 문제 핵심

이 문제는 2022년을 기준으로 하며 태어난 해에 1살이 되는 방식으로 나이를 셉니다. 그래서 단순히 `2022 - age`를 계산하면 한 해가 모자랍니다. 출생 연도는 `2022 - age + 1`, 즉 `2023 - age`입니다.

## 💭 먼저 생각해 보기

2022년에 1살인 사람은 몇 년에 태어났을까요? 답은 2022년입니다. 이 값을 `2023 - 1`과 비교해 식을 확인해 보세요.

## 🧪 예제 이해하기

2022년에 25살이라면 `2023 - 25`를 계산합니다. 출생 연도는 1998년입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

기준 연도 다음 수인 2023에서 나이를 뺍니다. 계산한 출생 연도를 변수에 담아 반환합니다.

### 🐍 Python 코드

```python
def solution(age):
    birth_year = 2023 - age
    return birth_year
```

### 📖 코드 해설

`birth_year`라는 이름은 변수에 출생 연도가 들어 있다는 뜻을 바로 보여 줍니다. `return`은 계산 결과를 함수 밖으로 돌려줍니다.

### ⏱️ 시간 복잡도

뺄셈을 한 번 하므로 시간 복잡도는 `O(1)`입니다.

### 💾 공간 복잡도

결과를 담는 변수 하나만 사용하므로 공간 복잡도는 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 문제의 기준은 현재 연도가 아니라 2022년입니다.
- 태어난 해를 1살로 세기 때문에 1을 더해야 합니다.
- 값을 화면에 출력하는 `print()` 대신 값을 돌려주는 `return`을 사용합니다.
