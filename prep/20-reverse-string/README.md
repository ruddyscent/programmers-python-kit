# 뒤집힌 문자열

- Stage: Python Prep 20

- Status: 학습 자료 준비됨 (Programmers 채점 미확인)

## 이 문제에서 배우는 것

문자열의 마지막 글자부터 첫 글자까지 거꾸로 읽는 방법을 연습합니다. `while` 반복문에서는 인덱스로 현재 위치를 나타냅니다. 인덱스를 직접 바꾸면 원하는 순서로 글자를 꺼냅니다.

## 문제 핵심

문자열의 마지막 인덱스는 `len(my_string) - 1`입니다. 그 위치에서 시작해 인덱스를 1씩 줄이면 글자를 뒤에서부터 읽습니다.

## 먼저 생각해 보기

`"python"`의 각 글자 아래에 0부터 인덱스를 써 보세요. 마지막 인덱스부터 0까지 이동하며 만나는 글자를 차례대로 적어 봅니다.

## 예제 이해하기

`"python"`의 마지막 글자는 `n`입니다. 뒤에서부터 `n`, `o`, `h`, `t`, `y`, `p` 순서로 읽어 붙이면 `"nohtyp"`이 됩니다.

## 풀이 1. 인덱스를 직접 움직이는 방법

### 아이디어

1. 마지막 글자의 인덱스를 구합니다.
2. 인덱스가 0 이상인 동안 그 위치의 글자를 결과에 붙입니다.
3. 글자를 하나 붙일 때마다 인덱스를 1 줄입니다.
4. 첫 글자까지 붙인 뒤 결과를 돌려줍니다.

### Python 코드

```python
def solution(my_string):
    answer = ""
    index = len(my_string) - 1

    while index >= 0:
        answer += my_string[index]
        index -= 1

    return answer
```

### 코드 해설

길이가 6인 문자열의 인덱스는 0부터 5까지이므로 마지막 인덱스는 `6 - 1`입니다. `index -= 1`을 빠뜨리면 같은 글자만 계속 읽어 반복문이 끝나지 않습니다. `index`가 -1이 되면 모든 글자를 읽은 것이므로 반복을 멈춥니다.

### 반복 횟수와 저장 공간

문자열 길이가 `n`이라면 반복문은 `n`번 돕니다. 뒤집은 문자열을 저장하는 데 글자 `n`개만큼의 공간이 필요합니다.

## 풀이 2. 슬라이싱으로 뒤집는 방법

### 아이디어와 Python 코드

슬라이싱 `my_string[start:stop:step]`의 세 번째 값은 이동 간격입니다. 이동 간격을 `-1`로 쓰고 시작과 끝을 비우면 문자열 전체를 뒤에서 앞으로 읽습니다.

```python
def solution(my_string):
    return my_string[::-1]
```

### 이 방법의 특징

Python의 슬라이싱을 알면 의도가 간단하게 드러납니다. 다만 `[::-1]`이 낯설다면 첫 번째 풀이로 인덱스의 움직임을 이해한 뒤 사용하는 편이 좋습니다. 이 코드도 뒤집은 새 문자열을 만듭니다.

## 실수하기 쉬운 점

- 마지막 인덱스는 `len(my_string)`이 아니라 `len(my_string) - 1`입니다.
- `while` 안에서 `index`를 반드시 줄여야 합니다.
- 슬라이싱의 이동 간격 `-1`에서 빼기 기호를 빠뜨리지 않습니다.

## 배운 것

- 문자열의 글자는 인덱스로 꺼냅니다.
- `while`에서 인덱스를 줄이면 뒤에서 앞으로 이동합니다.
- `[::-1]`은 Python에서 문자열 전체를 뒤집는 슬라이싱입니다.
