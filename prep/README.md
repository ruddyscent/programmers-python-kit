# 🐍 Python Prep

Python 문법을 처음 배우는 단계입니다. 알고리즘 이름을 외우기보다 함수, 조건문, 반복문, 리스트, 문자열을 사용해 작은 문제를 직접 해결하는 연습을 합니다.

## 🧭 학습 방법

1. 문제를 읽고 입력과 결과를 자기 말로 설명합니다.
2. 코드를 보기 전에 작은 예를 손으로 풀어 보세요.
3. `solution.py`에 있는 풀이를 보기 전에 먼저 혼자 코드를 작성해 봅니다.
4. 풀이를 확인한 뒤에는 각 줄이 하는 일을 설명해 보세요.
5. 프로그래머스 채점을 통과하고 1주일 뒤 힌트 없이 다시 풉니다.
