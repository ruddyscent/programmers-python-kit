# 🧩 짝수 홀수 개수

- Programmers ID: 120824
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120824
- Level: 0
- Stage: Python Prep 15
- Prerequisites: 리스트, `for`, `if`, 나머지 연산자 `%`
- Core concepts: 리스트 순회, 짝수 판별, 개수 세기

## 🎯 이 문제에서 배우는 것

리스트의 숫자를 하나씩 살펴보면서 조건에 맞는 개수를 셉니다. 짝수와 홀수처럼 두 종류를 세려면 각 종류의 개수를 저장할 변수를 따로 둡니다.

## 🔎 문제 핵심

숫자를 2로 나눈 나머지가 0이면 짝수입니다. 나머지가 0이 아니면 홀수입니다. 리스트를 처음부터 끝까지 한 번 돌며 알맞은 개수를 1씩 늘립니다.

## 💭 먼저 생각해 보기

`[2, 5, 8, 10]`을 손으로 살펴보세요. 각 숫자를 만날 때마다 `even_count`와 `odd_count` 중 어느 쪽을 늘려야 하는지 말해 봅니다.

## 🧪 예제 이해하기

`[2, 5, 8, 10]`에는 짝수 2, 8, 10이 있고 홀수 5가 있습니다. 짝수 개수를 먼저 담고 홀수 개수를 뒤에 담으면 결과는 `[3, 1]`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1. 짝수 개수와 홀수 개수를 0으로 시작합니다.
2. 리스트에서 숫자를 하나씩 꺼냅니다.
3. `number % 2 == 0`이면 짝수 개수를 늘리고 아니면 홀수 개수를 늘립니다.
4. 두 개수를 `[짝수 개수, 홀수 개수]` 순서로 돌려줍니다.

### 🐍 Python 코드

```python
def solution(num_list):
    even_count = 0
    odd_count = 0

    for number in num_list:
        if number % 2 == 0:
            even_count += 1
        else:
            odd_count += 1

    return [even_count, odd_count]
```

### 📖 코드 해설

`number % 2`는 숫자를 2로 나눈 나머지입니다. `even_count += 1`은 현재 짝수 개수에 1을 더해 다시 저장한다는 뜻입니다. 모든 정수는 짝수 또는 홀수이므로 `else`에서는 홀수 개수만 늘리면 됩니다.

### ⏱️ 반복 횟수와 저장 공간

숫자가 `n`개라면 반복문도 `n`번 돕니다. 개수를 저장하는 변수는 리스트 길이와 관계없이 두 개만 사용합니다.

## ⚠️ 실수하기 쉬운 점

- 결과의 순서는 `[짝수 개수, 홀수 개수]`입니다.
- `% 2 == 0`인 수가 짝수입니다.
- 숫자 0도 2로 나눈 나머지가 0이므로 짝수입니다.

## ✅ 배운 것

- `for`로 리스트의 모든 원소를 확인합니다.
- `%`로 짝수와 홀수를 구별합니다.
- 개수를 셀 때는 0에서 시작해 조건을 만족할 때마다 1을 더합니다.
