## 이 문제에서 배우는 것

리스트의 마지막 값부터 첫 값까지 거꾸로 방문하는 방법을 배웁니다. `range()`의 음수 간격과 슬라이싱의 간격도 익힙니다.

## 문제 핵심

값을 바꾸거나 정렬하는 문제가 아닙니다. 원래 리스트의 마지막 값이 결과의 첫 값이 되도록 순서만 뒤집어야 합니다.

## 먼저 생각해 보기

`['a', 'b', 'c']`의 인덱스는 0, 1, 2입니다. 마지막 인덱스 2부터 1, 0 순서로 값을 읽으면 `['c', 'b', 'a']`가 됩니다.

## 예제 이해하기

`num_list`가 `[4, 9, 2]`라면 뒤에서부터 2, 9, 4를 읽습니다. 반환할 리스트는 `[2, 9, 4]`입니다.

## 풀이 1. 인덱스를 거꾸로 방문하는 방법

### 아이디어

마지막 인덱스는 `len(num_list) - 1`입니다. 그곳에서 0번 인덱스까지 1씩 줄어드는 인덱스를 만들고 각 값을 새 리스트에 추가합니다.

### Python 코드

```python
def solution(num_list):
    reversed_list = []

    for index in range(len(num_list) - 1, -1, -1):
        reversed_list.append(num_list[index])

    return reversed_list
```

### 코드 해설

`range(시작, 끝, 간격)`에서 간격을 `-1`로 주면 숫자가 하나씩 작아집니다. 끝 숫자는 포함하지 않기 때문에 0까지 방문하려면 끝을 `-1`로 적습니다.

### 시간 복잡도

`num_list`의 길이를 `n`이라고 하면 모든 값을 한 번씩 방문합니다. 시간 복잡도는 `O(n)`입니다.

### 공간 복잡도

원소 `n`개를 담는 새 리스트를 만듭니다. 반환할 결과를 포함한 공간 복잡도는 `O(n)`입니다.

## 풀이 2. 슬라이싱 사용하기

### 아이디어

슬라이싱은 `리스트[시작:끝:간격]` 모양으로 리스트의 일부를 복사합니다. 시작과 끝을 비우고 간격을 `-1`로 두면 전체를 뒤에서 앞으로 복사합니다.

### Python 코드

```python
def solution(num_list):
    return num_list[::-1]
```

### 풀이의 특징

Python에서 리스트를 뒤집을 때 자주 쓰는 표현입니다. 새 리스트를 만들기 때문에 원래 `num_list`는 바뀌지 않습니다. 모든 원소를 복사하므로 시간과 공간 복잡도는 모두 `O(n)`입니다.

## 실수하기 쉬운 점

- 마지막 인덱스는 `len(num_list)`가 아니라 `len(num_list) - 1`입니다.
- 거꾸로 가려면 `range()`의 간격이 음수여야 합니다.
- `num_list.sort()`는 값을 크기순으로 정렬하므로 이 문제의 동작과 다릅니다.

## 배운 것

- 인덱스로 리스트를 뒤에서부터 읽습니다.
- `range()`의 간격에는 음수도 넣습니다.
- `[::-1]`은 원본을 건드리지 않고 뒤집힌 복사본을 만듭니다.
