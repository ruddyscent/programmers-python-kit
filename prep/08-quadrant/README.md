## 이 문제에서 배우는 것

리스트에서 x좌표와 y좌표를 꺼내고 두 수의 부호를 함께 살펴보는 연습을 합니다. `and`는 왼쪽 조건과 오른쪽 조건이 모두 참일 때만 참이 됩니다.

## 문제 핵심

`dot[0]`은 x좌표이고 `dot[1]`은 y좌표입니다. x와 y가 양수인지 음수인지에 따라 사분면 번호가 정해집니다. 두 좌표에는 0이 들어오지 않으므로 축 위의 점은 생각하지 않아도 됩니다.

## 먼저 생각해 보기

코드를 쓰기 전에 다음 네 경우를 말로 나누어 보세요.

- x 양수, y 양수
- x 음수, y 양수
- x 음수, y 음수
- x 양수, y 음수

## 예제 이해하기

`dot`이 `[5, -2]`라면 x는 양수이고 y는 음수입니다. 따라서 이 점은 제4사분면에 있습니다.

## 풀이 1. 이해하기 쉬운 방법

### 아이디어

x와 y를 각각 변수에 담습니다. 앞의 세 사분면을 차례로 확인하고 바로 번호를 반환합니다. 세 조건에 모두 맞지 않으면 남은 경우는 제4사분면입니다.

### Python 코드

```python
def solution(dot):
    x = dot[0]
    y = dot[1]

    if x > 0 and y > 0:
        return 1
    if x < 0 and y > 0:
        return 2
    if x < 0 and y < 0:
        return 3
    return 4
```

### 코드 해설

`x > 0 and y > 0`은 두 좌표가 모두 양수인지 묻습니다. 조건이 참이면 `return`으로 답을 돌려주며 함수가 끝납니다. 그래서 다음 `if`는 앞의 경우가 아니었을 때만 확인됩니다.

### 시간 복잡도

입력 크기와 관계없이 최대 세 조건만 확인합니다. 시간 복잡도는 `O(1)`입니다.

### 공간 복잡도

x와 y를 담는 변수 두 개만 사용합니다. 공간 복잡도는 `O(1)`입니다.

## 실수하기 쉬운 점

- `dot[0]`과 `dot[1]`의 뜻을 바꾸지 마세요.
- 한 조건 안에서 두 비교를 연결할 때 `and`를 빼먹지 마세요.
- 음수 비교에는 `< 0`을 사용합니다.

## 배운 것

- 리스트의 값은 인덱스로 꺼냅니다.
- `and`로 두 조건이 모두 참인지 확인합니다.
- `return`을 만나면 함수는 곧바로 끝납니다.
