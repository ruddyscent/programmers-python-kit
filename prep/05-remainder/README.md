# 🧩 나머지 구하기

- Programmers ID: 120810
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120810
- Level: 0
- Stage: Python Prep 05
- Prerequisites: 정수, 나눗셈, 함수, `return`
- Core concepts: 나머지 연산자 `%`

## 🎯 이 문제에서 배우는 것

나눗셈을 하고 남은 수를 구하는 `%` 연산자를 배웁니다. 나머지는 짝수와 홀수를 구분하거나 일정한 간격으로 반복할 때도 자주 씁니다.

## 🔎 문제 핵심

`num1`을 `num2`로 나눈 나머지를 반환합니다.

## 💭 먼저 생각해 보기

1. 사탕 14개를 4명에게 똑같이 나누면 몇 개가 남나요?
2. 몫과 나머지 가운데 이 문제에서 필요한 것은 무엇인가요?
3. Python에서 나머지를 구하는 연산자는 무엇인가요?

## 🧪 예제 이해하기

`num1`이 14이고 `num2`가 4라면 4씩 세 묶음을 만들고 2가 남습니다. `14 % 4`의 결과는 2입니다.

## 🛠️ 풀이 1. 나머지 연산자 사용하기

### 💡 아이디어

`%` 연산자로 나눗셈 뒤에 남는 수를 바로 구합니다.

### 🐍 Python 코드

```python
def solution(num1, num2):
    answer = num1 % num2
    return answer
```

### 📖 코드 해설

`num1 % num2`는 `num1`을 `num2`로 나눈 나머지입니다. 나누어떨어지면 결과는 0입니다.

### ⏱️ 시간 복잡도

나머지 계산을 한 번 하므로 `O(1)`입니다.

### 💾 공간 복잡도

결과 변수 하나를 사용하므로 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `//`는 몫을 구하고 `%`는 나머지를 구합니다.
- `num2 % num1`로 순서를 바꾸지 않도록 식을 읽어 보세요.

## ✅ 배운 것

- `%`는 나눗셈의 나머지를 구합니다.
- 나누어떨어지는 두 수의 나머지는 0입니다.
