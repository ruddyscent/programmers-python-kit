## 이 문제에서 배우는 것

`if`, `elif`, `else`를 사용해 한 값을 여러 조건으로 나누는 방법을 배웁니다. 90도와 180도처럼 구간이 갈리는 지점을 **경곗값**이라고 합니다.

## 문제 핵심

주어진 각 `angle`을 네 종류로 나누어 번호를 반환합니다.

- 90도보다 작으면 예각이므로 1
- 90도이면 직각이므로 2
- 90도보다 크고 180도보다 작으면 둔각이므로 3
- 180도이면 평각이므로 4

## 먼저 생각해 보기

1. 89도와 90도는 같은 종류인가요?
2. 179도와 180도는 어떻게 나뉘나요?
3. 앞에서 이미 확인한 조건을 뒤에서 다시 검사해야 할까요?

## 예제 이해하기

`angle`이 120이면 90보다 크고 180보다 작습니다. 둔각이므로 3을 반환합니다.

## 풀이 1. 작은 각부터 차례로 확인하기

### 아이디어

작은 범위부터 검사합니다. `if`가 거짓이면 다음 `elif`를 확인하고 모든 조건이 거짓이면 `else`를 실행합니다. 앞에서 범위를 확인했다면 뒤에서는 다시 검사할 필요가 없습니다.

### Python 코드

```python
def solution(angle):
    if angle < 90:
        return 1
    elif angle == 90:
        return 2
    elif angle < 180:
        return 3
    else:
        return 4
```

### 코드 해설

먼저 `if`에서 90도보다 작은지 확인합니다. 거짓이면 첫 번째 `elif`에서 90도인지 검사합니다. 이것도 거짓이라면 두 번째 `elif`에서 180도보다 작은지 확인합니다. 180도는 세 조건에 모두 해당하지 않으므로 `else`에서 처리합니다. 이 조건 묶음에서는 참인 블록 하나만 실행됩니다.

### 시간 복잡도

조건을 많아야 세 번 확인하므로 `O(1)`입니다.

### 공간 복잡도

추가 자료 모음을 만들지 않으므로 `O(1)`입니다.

## 실수하기 쉬운 점

- 90도와 180도를 어느 구간에 넣을지 정확히 확인하세요.
- `angle <= 90`이라고 쓰면 90도를 예각으로 잘못 나누게 됩니다.
- 조건문 아래의 코드는 네 칸 들여씁니다.

## 배운 것

- 여러 조건은 겹치지 않도록 순서를 정합니다.
- `elif`는 앞의 조건이 거짓일 때 다음 조건을 확인합니다.
- `else`는 앞의 조건이 모두 거짓일 때 실행합니다.
- 경곗값에서는 `<`, `==`, `<=`의 차이를 꼼꼼히 봐야 합니다.
