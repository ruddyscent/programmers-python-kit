# 🧩 문자열 정렬하기 (1)

- Programmers ID: 120850
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120850
- Level: 0
- Stage: Python Prep 19
- Prerequisites: 문자열과 리스트, `for`, `if`, `int()`, `sorted()`
- Core concepts: 숫자 문자 찾기, 형 변환, 오름차순 정렬

## 🎯 이 문제에서 배우는 것

문자열 속 숫자 문자를 찾아 실제 정수로 바꾸고 리스트에 모아 정렬하는 과정을 연습합니다. `isdigit()`은 문자가 숫자인지 확인하고 `int()`는 숫자 문자를 정수로 바꿉니다.

## 🔎 문제 핵심

문자열에서 숫자만 찾는 것으로 끝나지 않습니다. 숫자 문자를 정수로 바꿔 리스트에 담고 작은 수부터 정렬해야 합니다. 예를 들어 문자 `"7"`을 정수 `7`로 바꿔야 결과가 정수 리스트가 됩니다.

## 💭 먼저 생각해 보기

`"c8a2b5"`를 보고 숫자 문자만 동그라미 쳐 보세요. 찾은 숫자를 정수 리스트에 담은 다음 작은 순서로 놓아 봅니다.

## 🧪 예제 이해하기

`"c8a2b5"`에서 찾은 숫자 문자는 `"8"`, `"2"`, `"5"`입니다. 이를 정수로 바꾸면 `[8, 2, 5]`이고 오름차순으로 정렬하면 `[2, 5, 8]`입니다.

## 🛠️ 풀이 1. 이해하기 쉬운 방법

### 💡 아이디어

1. 숫자를 담을 빈 리스트를 만듭니다.
2. 문자열의 글자를 하나씩 확인합니다.
3. `isdigit()`이 참이면 `int()`로 정수로 바꾸어 리스트에 추가합니다.
4. `sorted(numbers)`로 작은 수부터 정렬한 새 리스트를 돌려줍니다.

### 🐍 Python 코드

```python
def solution(my_string):
    numbers = []

    for character in my_string:
        if character.isdigit():
            numbers.append(int(character))

    return sorted(numbers)
```

### 📖 코드 해설

`character.isdigit()`은 현재 글자가 숫자라면 `True`를 돌려줍니다. `numbers.append(...)`는 리스트 맨 뒤에 값을 하나 추가합니다. `sorted(numbers)`는 원래 리스트를 바꾸지 않고 정렬된 새 리스트를 만듭니다.

### ⏱️ 반복 횟수와 저장 공간

문자열 길이를 `n`, 찾은 숫자 개수를 `k`라고 하겠습니다. 글자 확인은 `n`번 하고 `k`개의 숫자를 정렬합니다. `numbers`와 정렬된 결과 리스트에는 각각 `k`개의 정수가 들어갑니다.

## ⚠️ 실수하기 쉬운 점

- 결과에는 문자열이 아니라 정수가 들어가야 합니다.
- 숫자를 찾은 순서 그대로 돌려주지 말고 오름차순으로 정렬합니다.
- 같은 숫자가 여러 번 나오면 그만큼 모두 결과에 남겨야 합니다.
- `sorted(numbers)`는 새 리스트를 만들고 `numbers.sort()`는 리스트 자체를 바꿉니다.

## ✅ 배운 것

- `isdigit()`으로 숫자 문자를 찾습니다.
- `int()`로 숫자 문자를 정수로 바꿉니다.
- `append()`로 리스트에 값을 추가하고 `sorted()`로 오름차순 정렬합니다.
