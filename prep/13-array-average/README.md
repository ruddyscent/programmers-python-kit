# 🧩 배열의 평균값

- Programmers ID: 120817
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120817
- Level: 0
- Stage: Python Prep 13
- Prerequisites: 함수, 변수, 리스트, `for`, `len()`, 덧셈, `/`, `return`
- Core concepts: 합계 누적, 리스트 길이, 평균 계산, `sum()`, `min()`, `max()`

## 🎯 이 문제에서 배우는 것

리스트의 합계를 반복문으로 구하고 값의 개수로 나누어 평균을 계산합니다. `/`와 `//`가 서로 다른 결과를 만든다는 점도 확인합니다.

## 🔎 문제 핵심

평균을 구하려면 모든 값을 더해 합계를 만듭니다. 그 합계를 값의 개수로 나눕니다. 입력 리스트에는 값이 하나 이상 있으므로 0으로 나누는 경우는 없습니다.

## 💭 먼저 생각해 보기

`[2, 5, 8]`을 손으로 계산해 보세요. 합계는 15이고 값은 3개이므로 평균은 `15 / 3`, 즉 5입니다.

## 🧪 예제 이해하기

`numbers`가 `[1, 4, 7, 10]`이면 합계는 22이고 개수는 4입니다. 평균은 `22 / 4`인 5.5입니다.

## 🛠️ 풀이 1. 합계를 직접 모으는 방법

### 💡 아이디어

`total`을 0으로 시작합니다. 리스트의 수를 하나씩 더한 뒤, 전체 개수인 `len(numbers)`로 나눕니다.

### 🐍 Python 코드

```python
def solution(numbers):
    total = 0

    for number in numbers:
        total += number

    return total / len(numbers)
```

### 📖 코드 해설

`total += number`는 `total = total + number`와 같은 뜻입니다. 반복이 끝나면 `total`에는 모든 수의 합이 들어 있습니다. `/`로 나누면 5.5처럼 소수 부분이 있는 평균도 계산됩니다.

### ⏱️ 시간 복잡도

`numbers`의 길이를 `n`이라고 하면 모든 값을 한 번씩 더합니다. 시간 복잡도는 `O(n)`입니다.

### 💾 공간 복잡도

합계를 담는 변수만 더 사용합니다. 공간 복잡도는 `O(1)`입니다.

## ✨ 풀이 2. `sum()` 사용하기

### 💡 아이디어

Python의 `sum(numbers)`는 리스트 안의 수를 모두 더해 줍니다.

### 🐍 Python 코드

```python
def solution(numbers):
    return sum(numbers) / len(numbers)
```

### 🔍 풀이의 특징

합계를 구하는 뜻이 코드에 바로 드러납니다. `sum()`도 모든 값을 한 번씩 확인하므로 시간 복잡도는 `O(n)`이고 추가 공간 복잡도는 `O(1)`입니다.

## 🔬 함께 알아보기. `min()`과 `max()`

숫자 리스트에서 가장 작은 값은 `min()`, 가장 큰 값은 `max()`로 찾습니다.

```python
numbers = [6, 2, 9, 4]

smallest = min(numbers)  # 2
largest = max(numbers)   # 9
```

이 문제의 평균 계산에는 `min()`과 `max()`가 필요하지 않습니다. 두 함수는 리스트를 처음부터 끝까지 살펴보므로 각각 `O(n)`의 시간이 걸리고 추가 공간은 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- 평균은 합계를 값의 개수로 나눈 수입니다.
- `//`를 사용하면 소수 부분이 버려지므로 `/`를 사용합니다.
- `len(numbers)`는 마지막 인덱스가 아니라 리스트에 든 값의 개수입니다.

## ✅ 배운 것

- 반복하면서 값을 한 변수에 계속 더합니다.
- `len()`은 리스트의 길이를 알려 줍니다.
- `sum()`으로 숫자 리스트의 합계를 구합니다.
- `min()`과 `max()`로 가장 작은 값과 가장 큰 값을 찾습니다.
