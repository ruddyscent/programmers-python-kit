## 이 문제에서 배우는 것

1부터 어떤 수까지 차례로 반복하고 그중 조건에 맞는 값만 리스트에 모으는 방법을 배웁니다. `%` 연산자로 홀수를 찾는 연습도 합니다.

## 문제 핵심

1부터 `n`까지의 수 중 홀수만 오름차순으로 담아야 합니다. 어떤 수를 2로 나눈 나머지가 1이면 홀수입니다.

## 먼저 생각해 보기

1부터 8까지 적고 각 수를 2로 나눈 나머지를 표시해 보세요. 나머지가 1인 수만 왼쪽부터 읽으면 `[1, 3, 5, 7]`이 됩니다.

## 예제 이해하기

`n`이 6이면 확인할 수는 1, 2, 3, 4, 5, 6입니다. 이 가운데 홀수인 1, 3, 5만 모아 `[1, 3, 5]`를 반환합니다.

## 풀이 1. 이해하기 쉬운 방법

### 아이디어

`range(1, n + 1)`로 1부터 `n`까지 반복합니다. 현재 수가 홀수라면 결과 리스트에 추가합니다.

### Python 코드

```python
def solution(n):
    odd_numbers = []

    for number in range(1, n + 1):
        if number % 2 == 1:
            odd_numbers.append(number)

    return odd_numbers
```

### 코드 해설

`range()`의 끝 숫자는 반복에 포함되지 않습니다. 그래서 `n`도 확인하려면 끝에 `n + 1`을 적습니다. `number % 2 == 1`인 수만 `append()`합니다.

### 시간 복잡도

1부터 `n`까지 한 번씩 확인합니다. 시간 복잡도는 `O(n)`입니다.

### 공간 복잡도

홀수를 담는 결과 리스트가 필요합니다. 반환할 결과를 포함한 공간 복잡도는 `O(n)`입니다.

## 풀이 2. `range()`의 간격 사용하기

### 아이디어

`range(시작, 끝, 간격)`의 세 번째 값은 다음 수로 얼마나 이동할지 정합니다. 1에서 시작해 2씩 건너가며 홀수만 만듭니다.

### Python 코드

```python
def solution(n):
    return list(range(1, n + 1, 2))
```

### 풀이의 특징

홀수인지 매번 검사하지 않고 `range()`가 처음부터 홀수만 만듭니다. `range` 자체는 리스트가 아니므로 `list()`로 감싸 반환할 리스트를 만듭니다. 결과 원소 수만큼 작업하고 저장하므로 시간과 공간은 모두 `O(n)`입니다.

## 실수하기 쉬운 점

- `range(1, n)`이라고 쓰면 `n`이 홀수여도 결과에서 빠집니다.
- 홀수는 2로 나눈 나머지가 1입니다.
- `range(...)`를 그대로 반환하지 말고 문제에서 요구한 리스트로 바꿉니다.

## 배운 것

- `%`로 홀수와 짝수를 구별합니다.
- `range()`의 끝 숫자는 포함되지 않습니다.
- `range()`의 세 번째 값으로 숫자 사이의 간격을 정합니다.
