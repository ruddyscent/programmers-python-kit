# 🧩 두 수의 차 구하기

- Programmers ID: 120803
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120803
- Level: 0
- Stage: Python Prep 02
- Prerequisites: 정수, 함수, 매개변수, `return`
- Core concepts: 뺄셈 연산자 `-`, 계산 순서

## 🎯 이 문제에서 배우는 것

두 수의 순서를 지켜 뺄셈하는 법을 배웁니다. 뺄셈은 앞뒤 순서를 바꾸면 결과가 달라집니다.

## 🔎 문제 핵심

첫 번째 수 `num1`에서 두 번째 수 `num2`를 뺀 값을 반환합니다. 식은 `num1 - num2`입니다.

## 💭 먼저 생각해 보기

1. 문제에서 어느 수를 먼저 빼라고 했는지 확인하세요.
2. 뺄셈 결과가 음수가 되어도 괜찮을까요?
3. 계산 결과를 어떻게 함수 밖으로 돌려줄까요?

## 🧪 예제 이해하기

`num1`이 8이고 `num2`가 13이라면 `8 - 13`을 계산합니다. 결과는 -5입니다.

## 🛠️ 풀이 1. 순서대로 빼기

### 💡 아이디어

`num1` 뒤에 `- num2`를 붙여 문제에 나온 순서 그대로 계산합니다.

### 🐍 Python 코드

```python
def solution(num1, num2):
    answer = num1 - num2
    return answer
```

### 📖 코드 해설

`num1 - num2`는 첫 번째 수에서 두 번째 수를 뺍니다. 그 값을 `answer`에 넣고 `return`으로 돌려줍니다.

### ⏱️ 시간 복잡도

뺄셈을 한 번 하므로 `O(1)`입니다.

### 💾 공간 복잡도

결과 변수 하나를 사용하므로 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `num2 - num1`로 순서를 바꾸지 않도록 주의하세요.
- 결과가 음수라고 해서 잘못된 계산은 아닙니다.

## ✅ 배운 것

- `-`는 앞의 수에서 뒤의 수를 뺍니다.
- 뺄셈에서는 수의 순서가 중요합니다.
