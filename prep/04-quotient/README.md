# 🧩 몫 구하기

- Programmers ID: 120805
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120805
- Level: 0
- Stage: Python Prep 04
- Prerequisites: 정수, 나눗셈, 함수, `return`
- Core concepts: 정수 나눗셈 연산자 `//`, 몫

## 🎯 이 문제에서 배우는 것

나눗셈 결과에서 몫만 구하는 `//` 연산자를 배웁니다. `/`와 `//`의 결과가 어떻게 다른지도 살펴봅니다.

## 🔎 문제 핵심

`num1`을 `num2`로 나눈 몫을 반환합니다. 이 문제의 입력은 양의 정수이므로 `//`를 쓰면 원하는 몫을 바로 얻습니다.

## 💭 먼저 생각해 보기

1. 17개를 한 묶음에 5개씩 담으면 가득 찬 묶음은 몇 개인가요?
2. 남는 2개는 몫에 포함될까요?
3. `/`와 `//` 중 어느 연산자가 몫을 구할까요?

## 🧪 예제 이해하기

`num1`이 17이고 `num2`가 5라면 `17 // 5`를 계산합니다. 5가 세 번 들어가고 2가 남으므로 몫은 3입니다.

## 🛠️ 풀이 1. 정수 나눗셈 사용하기

### 💡 아이디어

`//`로 나누면 나눗셈의 몫을 정수로 얻습니다.

### 🐍 Python 코드

```python
def solution(num1, num2):
    answer = num1 // num2
    return answer
```

### 📖 코드 해설

`num1 // num2`는 `num1`을 `num2`로 나눈 몫을 구합니다. 예를 들어 `17 // 5`는 3입니다.

### ⏱️ 시간 복잡도

나눗셈을 한 번 하므로 `O(1)`입니다.

### 💾 공간 복잡도

결과 변수 하나를 사용하므로 `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `/`를 쓰면 `17 / 5`처럼 소수점이 있는 결과 `3.4`가 나옵니다.
- 나누는 수와 나누어지는 수의 순서를 바꾸지 마세요.

## ✅ 배운 것

- `//`는 정수 나눗셈의 몫을 구합니다.
- `/`는 일반 나눗셈 결과를 구합니다.
