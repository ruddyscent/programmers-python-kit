# 특정 문자 제거하기

## 이 문제에서 배우는 것

원하지 않는 글자를 직접 지우는 대신 남길 글자만 새 문자열에 담습니다. 이렇게 하면 원래 문자열의 순서도 그대로 남습니다.

## 문제 핵심

문자열의 모든 글자를 `letter`와 비교합니다. 두 글자가 다를 때만 결과 문자열에 붙이면 `letter`와 같은 글자는 모두 빠집니다.

## 먼저 생각해 보기

`"banana"`에서 `"a"`를 뺀다고 생각해 보세요. 왼쪽부터 한 글자씩 보면서 남길 글자와 건너뛸 글자를 구분해 봅니다.

## 예제 이해하기

`"banana"`의 글자를 차례대로 확인하면 `b`, `n`, `n`만 남습니다. 따라서 결과는 `"bnn"`입니다.

## 풀이 1. 이해하기 쉬운 방법

### 아이디어

1. 결과를 담을 빈 문자열을 만듭니다.
2. 원래 문자열에서 글자를 하나씩 꺼냅니다.
3. 글자가 `letter`와 다를 때만 결과 뒤에 붙입니다.
4. 모든 글자를 확인한 뒤 결과를 돌려줍니다.

### Python 코드

```python
def solution(my_string, letter):
    answer = ""

    for character in my_string:
        if character != letter:
            answer += character

    return answer
```

### 코드 해설

`!=`는 두 값이 다르다는 뜻입니다. `character != letter`가 참이면 그 글자는 제거할 대상이 아니므로 `answer`에 붙입니다. 조건이 거짓인 글자는 아무 일도 하지 않고 다음 글자로 넘어갑니다.

### 반복 횟수와 저장 공간

문자열 길이가 `n`이라면 글자를 `n`번 확인합니다. 새 문자열에는 제거되지 않은 글자들이 저장됩니다.

## 실수하기 쉬운 점

- `letter`가 나온 첫 자리만 빼는 것이 아니라 같은 글자를 모두 빼야 합니다.
- `"A"`와 `"a"`는 서로 다른 글자입니다.
- 원래 문자열을 바꾸려 하지 말고 새 문자열을 만듭니다.

## 배운 것

- `!=`로 두 값이 다른지 확인합니다.
- 조건을 만족하는 글자만 모아 새 문자열을 만듭니다.
- 글자를 골라도 남은 글자의 순서는 바뀌지 않습니다.
