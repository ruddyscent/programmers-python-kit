## 이 문제에서 배우는 것

함수가 받은 두 수를 더하고 계산한 값을 돌려주는 흐름을 배웁니다. `num1`과 `num2`는 함수 안으로 들어오는 값이며 **매개변수**라고 부릅니다.

## 문제 핵심

두 정수 `num1`, `num2`를 더한 결과를 반환합니다. 화면에 출력하는 문제가 아니므로 `print()` 대신 `return`을 써야 합니다.

## 먼저 생각해 보기

1. `num1`과 `num2` 사이에 어떤 연산자를 놓아야 할까요?
2. 계산한 값을 `answer`에 저장해 보세요.
3. 함수 밖으로 결과를 보내려면 어떤 명령을 써야 할까요?

## 예제 이해하기

`num1`이 -7이고 `num2`가 12라면 `-7 + 12`를 계산합니다. 결과는 5입니다.

## 풀이 1. 계산한 값을 변수에 담기

### 아이디어

`+`로 두 수를 더합니다. 결과를 `answer`에 저장한 뒤 반환합니다.

### Python 코드

```python
def solution(num1, num2):
    answer = num1 + num2
    return answer
```

### 코드 해설

`answer = num1 + num2`는 오른쪽의 덧셈을 먼저 계산하고 그 결과를 `answer`에 넣습니다. `return answer`는 저장한 값을 함수를 부른 곳으로 돌려줍니다.

### 시간 복잡도

덧셈을 한 번 하므로 입력값의 크기와 관계없이 계산 횟수는 일정합니다. `O(1)`입니다.

### 공간 복잡도

결과를 담는 변수 하나만 사용합니다. `O(1)`입니다.

## 실수하기 쉬운 점

- `+`를 빼먹고 두 변수 이름을 붙여 쓰면 안 됩니다.
- `print(answer)`는 값을 보여줄 뿐, 채점기에 결과를 돌려주지 않습니다.

## 배운 것

- `+`는 두 수를 더합니다.
- `=`는 계산한 값을 변수에 저장합니다.
- `return`은 함수의 결과를 돌려줍니다.
