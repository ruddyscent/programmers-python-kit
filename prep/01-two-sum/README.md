# 🧩 두 수의 합 구하기

- Programmers ID: 120802
- Official link: https://school.programmers.co.kr/learn/courses/30/lessons/120802
- Level: 0
- Stage: Python Prep 01
- Prerequisites: 정수, 두 수의 덧셈
- Core concepts: 함수, 매개변수, `return`, 덧셈 연산자 `+`, 변수에 값 저장하기, 들여쓰기

## 🎯 이 문제에서 배우는 것

두 수를 더하는 함수를 만들어 봅니다. **함수**는 이름을 붙여 둔 코드 묶음입니다. 이 문제에서는 채점기가 `solution`이라는 이름으로 함수를 부릅니다.

`def`는 함수를 만들 때 쓰는 말입니다. 그 뒤에 함수 이름 `solution`을 적고 괄호 안에는 받을 값의 이름을 씁니다. `(num1, num2)`에서 `num1`과 `num2`를 **매개변수**라고 합니다. 함수 안에서는 받은 두 수를 이 이름으로 사용합니다.

함수의 첫 줄 끝에는 콜론 `:`을 붙입니다. 다음 줄부터 함수가 할 일을 적습니다. 줄 앞에 공백을 넣어 오른쪽으로 옮기는 것을 **들여쓰기**라고 합니다. 파이썬은 들여쓰기로 코드가 어디에 속하는지 구분합니다.

**변수**는 값을 저장해 두고 이름으로 다시 사용할 때 씁니다. `answer = num1 + num2`는 `+`로 두 수를 더하고 `=`로 그 값을 `answer`에 저장합니다. `return answer`는 저장한 값을 함수를 부른 곳으로 돌려주고 함수를 끝냅니다.

## 🔎 문제 핵심

두 정수 `num1`, `num2`를 더한 결과를 반환합니다. 화면에 출력하는 문제가 아니므로 `print()` 대신 `return`을 써야 합니다.

## 💭 먼저 생각해 보기

1. `num1`과 `num2` 사이에 어떤 연산자를 놓아야 할까요?
2. 계산한 값을 `answer`에 저장해 보세요.
3. 함수 밖으로 결과를 보내려면 어떤 명령을 써야 할까요?

## 🧪 예제 이해하기

`num1`이 -7이고 `num2`가 12라면 `-7 + 12`를 계산합니다. 결과는 5입니다.

## 🛠️ 풀이 1. 계산한 값을 변수에 담기

### 💡 아이디어

`+`로 두 수를 더합니다. 결과를 `answer`에 저장한 뒤 반환합니다.

### 🐍 Python 코드

아래 코드에서 `answer`와 `return` 앞에는 각각 공백이 네 칸 있습니다. 두 줄 모두 `solution` 함수 안에서 할 일이므로 시작 위치를 맞춥니다.

```python
def solution(num1, num2):
    answer = num1 + num2
    return answer
```

들여쓸 때는 다음 규칙을 지켜 보세요.

- 이 코드의 `def` 줄은 맨 왼쪽에서 시작합니다. 함수 안의 두 줄은 스페이스 키로 네 칸 들여씁니다. 파이썬이 꼭 네 칸만 허용하는 것은 아니지만 보통 네 칸을 사용하며 이 자료도 그 약속을 따릅니다.
- 같은 묶음에 속한 줄은 들여쓰기 칸 수를 맞춥니다. 위 코드에서 `return`만 더 들여쓰거나 맨 왼쪽으로 옮기면 오류가 납니다.
- 탭 문자와 공백을 섞지 마세요. 편집기가 자동으로 들여써 주었다면 공백을 또 넣을 필요는 없습니다. 자동 들여쓰기가 없다면 스페이스 키로 네 칸을 넣으세요.

### 📖 코드 해설

`answer = num1 + num2`는 오른쪽의 덧셈을 먼저 계산하고 그 결과를 `answer`에 넣습니다. `return answer`는 저장한 값을 함수를 부른 곳으로 돌려줍니다.

### ⏱️ 시간 복잡도

덧셈을 한 번 하므로 입력값의 크기와 관계없이 계산 횟수는 일정합니다. `O(1)`입니다.

### 💾 공간 복잡도

결과를 담는 변수 하나만 사용합니다. `O(1)`입니다.

## ⚠️ 실수하기 쉬운 점

- `+`를 빼먹고 두 변수 이름을 붙여 쓰면 안 됩니다.
- `print(answer)`는 값을 보여줄 뿐, 채점기에 결과를 돌려주지 않습니다.
- `IndentationError`가 나오면 들여쓰기부터 확인하세요. `answer`와 `return` 앞에 공백 네 칸이 있는지, 두 줄의 시작 위치가 같은지 살펴보세요.

## ✅ 배운 것

- `+`는 두 수를 더합니다.
- `=`는 계산한 값을 변수에 저장합니다.
- `return`은 함수의 결과를 돌려줍니다.
- 파이썬은 들여쓰기로 코드의 묶음을 구분합니다. 함수 안에서 할 일은 한 단계 들여씁니다.
